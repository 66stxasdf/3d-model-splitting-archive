## 09-最小证伪实验（35 MB）· L1~L8 证据链

本轮主线的**结论与原始证据都在这里**。入口三件：

| 文件 | 是什么 |
|---|---|
| `evidence_chain.html` / `.png` | 八层证据链，单文件离线，点左侧任一层展开该轮原始图与数值；数字现场取八份 JSON，未硬编码 |
| `README.md` | 全链路结论正文（L1~L8 逐层追加，含被撤销/降级的旧结论留痕） |
| `viewer.html` / `comparison.png` | Step4 对偶图 min-cut 单刀两件的交互预览与四面板对照 |

八层各打掉一个前提，**顺序不可跳**：

| 层 | 打的是什么 | 判定 |
|---|---|---|
| L1 证据 | 构造反例冒充实测 | 撤销；真资产 `upload` 焊后 边界=0 / 非流形=8 / 不水密 |
| L2 对照 | Step4 min-cut 链路 | `c̄=0.1379` vs 同场水平切 `0.6258` → 链路跑通（后被降级） |
| L3 口径 | 水平切是不是稻草人 | 锁高 Δ=0.008 → `c̄=0.4309`，回升占差距 59.6% → 对照失效 |
| L4 构念 | 代价场认不认得接缝 | 2,119 条真值缝上 `AUC=0.5185` → **Step3 几何代价场塌掉** |
| L5 能力 | 是特征选错还是几何量没信号 | 纯几何 CV 上界 0.6157；同层语义缝最强 disc 0.043 → **语义层是必需项** |
| L6 协议 | 「先建真值集」怎么做 | `seam_annotator.html` 离线盲标器（不加载 `cut_cost`）、`truth_power.py` 算标多少才够 |
| L7 放大 | 标面→推边稳不稳 | 1% 面错标 → 2.24× 预测缝、边 F1 0.616；拓扑闭合查不出整条缝错位 |
| L8 可学性 | L7 的高 F1 是成绩还是上界 | **是上界**。真从网格零调参预测，同 acc 下边 F1 仅为 L7 预期的 11.58%；规则标签 93.6% 可被纯空间分区复述 → 不能当监督集 |

**站得住**：图割求解链路、非流形/绕序质检、Δ 消融、边级标注协议、误差放大与可学性基线。
**已撤销**：`c̄<0.4` 判据、水平切当对手、闭合环当有效性验真、规则标签当语义真值、`1e-3·diag` 上限。
**硬阻塞**：人工设计师接缝真值集 / 可信语义监督 / 与真实装配标定过的下游指标。真值到手前不在 `cut_cost` 上做数值打磨。

回答「截图里那张彩色 3D 图是什么意思 / 14 件怎么分别 / 要怎么打印」。**不修改任何原始 STL**。

| 文件 | 是什么 |

| `print_manual.html` | 3.46 MB 单文件离线 3D 打印手册；`?m=explode` 分件陈列、`?s=0..13` 单件聚焦、`?c=fil` 耗材色、Ctrl+P 出 2 页 |
| `astronaut_kid_14parts.3mf` | 14 object / 14 色 `basematerials` / 188,452 三角形，经 trimesh 读回逐件面数核对一致 |
| `print_worksheet.csv` / `.md` / `print_data.json` | 14 行排产作业单（朝向、支撑、耗材色、风险） |
| `assembly_check.json` | 装配实测原始数据 |
| `print_manual_printout.pdf` | 浏览器打印成品 2 页 |

两套颜色别混：截图彩虹色 = 14 类区分色；`manifest` 的 `rgb` = 建议耗材色（3MF 用这套）。
青色锯齿线 = 相邻面标签不同推出的 **2,119 条 / 1.57% 接缝边**，沿网格边走所以锯齿，既不是藏缝也不是切割路径。

> **打印前必读的硬伤**：19 对贴合分界面中位间隙 **0.1187 mm**、11 对互相内侵（最大 0.2935 mm）。
> 14 件是同一张连续表面切开后各自**原地加厚 1.2 mm** 的薄壳，配合面近乎零公差 →
> 1:1 打印会顶死，需单侧 0.15~0.25 mm 偏置 + 定位榫。本包只报告，不做修正；
> 也**未在真实切片软件中实测** 3MF 分色导入。

## 12-交互式画线分割（32 MB）· L9

把硬阻塞从「标注边」升级为「人直接画整条设计意图割线」，agent 只做闭环与执行切割；
工具刻意**不含** `cut_cost` / 语义预测 / 自动找缝。

| 文件 | 是什么 |
|---|---|
| `seam_draw.html` | 6.2 MB 单文件离线 3D 画线器：左键表面画线、右键旋转，松手才跑 9 万节点 Dijkstra |
| `split_from_drawing.py` | 后台 agent：读画线 JSON → 删面带 → BFS 分块 → fan 封盖 → STL/GLB/报告 |
| `my_seam_{short,back,plane}.json` / `split_*/` | 三种补全的真实前端输出与后台分割结果 |
| `completion_comparison.png` | 四面板对照，数字现场取 JSON |

实测（人只画 219 面，真值环参照 75,004 / 14,868 面）：最短补全 → 小件 2,222 面（偏差 85.1%）；
绕背 → 1,874 面（87.4%）；**沿画线平面 → 15,124 面（1.7%）**，体积 22.37 vs 22.68 cm³。
三种都分成 2 块且封盖后水密 → **「闭环成立」只证明切开了，证明不了切对位置**。
