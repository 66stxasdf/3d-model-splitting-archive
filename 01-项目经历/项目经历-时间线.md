## 阶段 3 · L9：从自动找缝转向人画割线（2026-11-06 ~ 11-07）

- 语义分割路线暂停；把硬阻塞从「标注边」升级为「人直接画整条设计意图割线」，agent 只做闭环与执行切割。
- 工具 `seam_draw.html` 刻意**不含** cut_cost / 语义预测 / 自动找缝。
- 实测（人只画 219 面）：最短补全小件 2,222 面（偏差 85.1%）；绕背 1,874 面（87.4%）；**沿画线平面 15,124 面（1.7%）**，体积 22.37 vs 22.68 cm³。三种都分成 2 块且封盖水密。
- 结论：**「闭环成立」只证明切开了，证明不了切对位置。**
- **11-07 晚** v2 升级：从按住拖拽改为单击落点 → 两点成段 → 贴表面测地 → 拖紫色中点改弧度 → 后台 `refine_seam.py` 平滑复验。面心 6688° → 边中点 4837°（−27.7%）→ Taubin 平滑 2110°（−68.5%）；v1 三种补全数字经 v2 复跑逐一吻合。

## 阶段 4 · 13 绑骨拆分与 L10~L17 迭代（2026-11-07 ~ 11-09）

- **11-07 夜**：微信收到 STL（87 MB / 1,745,172 面）。体检发现它本来就是 **23 个互不连通的封闭块**（边界 0 / 非流形 0 / 绕序一致 / 跨块共享顶点 0）。
  ⇒ 「拆件」= Blender 按松散块分离，不需要切缝；「绑骨」= 每顶点 100% 权重刚性蒙皮（STL 不自带权重，骨架现造）。骨架层级取零件间最近表面距离的 MST，root `J_13`。
  修掉一个真 bug：glTF MAT4 列主序，IBM 平移应取 `arr[3,0:3]` 而非 `arr[0:3,3]`。校验 G·IBM=I 误差 0、跨骨三角形 0、bind pose 位移 0。
- **L10 棱角根因**：用户反馈「所有模型都有尖锐棱角」。实测 5 个资产二面角中位 0.15~2.76°、≥30° 尖锐边仅 0.30~3.61%，几何上不成立；颗粒感主因是旧抽面 LOD + 点云渲染。三条自动变圆路线（Shade Smooth 仅 0.97% 像素差 / 全局 Taubin 饱和反转 / Bevel 被 clamp 钳死）全部撤销，改走路线 C：人工定线 → refine_seam.py → 按线切分 → 复用骨架。
- **L11 穿模修复**：源 STL 装甲板故意内嵌主体，拆成 23 个封闭实体后共占空间；Boolean DIFFERENCE + 0.0006 退让处理最严重 2 对，嵌入点 728/1500 → 0、652/1500 → 0。近共面处 signed_distance 符号会骗人，必须用射线奇偶判定。
- **L12 v2 结构优化**：8 组左右对 / 3 中线件 / 4 孤件，语义命名 + 镜像一致层级 + 7 个功能 Collection，零几何变更。
- **L13 v4 层级解耦**：修正「抬肩带动整条腿」（`L_Foot` 位移 0.571 → 0.000）；正负双向扫描生成 23 个可 mute 的 LIMIT_ROTATION；60° 摆臂穿模增量 3826 → 1872（仅修层级）→ 34（加约束）。
- **L14 细节分层**：审计 2,527,731 邻接边，中位二面角 2.38°、>30° 锐边 2.09% 但连成 11,017 条链；第三条 Bevel 路线被证伪。改做 21 个封闭圆管加强筋 + Fresnel 分色边界柔化；硬跳变 819 → 366（−55.3%）。
- **L15 清理**：碎块 = L14 加强筋在曲面退化成珠链，删除；红球是源 STL 的 `L_JointPin` 左髋球头，非误建物，改中性金属色保留；主推由 v5d 更新为 parts_v6.blend。
- **L16 髋球合并**：用户选「合并到相邻件」。BVH 实测球到 `L_Leg` 最小 0 / 中位 0.001492，用 `object.join` 并入 `L_Leg`（结构合并非布尔融合，源几何零损失）；修掉「球与腿是兄弟骨，摆腿时球脱开」。主体 23→22 件，骨骼/约束 23→22，9 项硬判定全 True。主推 = `parts_v7.blend`。
- **L17 网盘归档（11-09）**：13 个文件 / 1,738,201 B 上传至 `课题-语义自动分件/13-绑骨拆分-23件刚性蒙皮/`，回读 13/13 吻合；`.blend` 与大体过程制品按规则未传。

## 阶段 5 · L18 / L19 新模型真正切开几何（2026-11-09 ~ 11-10）

- **L18 横剖**：新 STL 25,000,084 B / 500,000 面 / 249,936 顶点 / **1 个连通块** / 水密；旧模型 1,745,172 面 / 23 个连通块。旧 23 件每层 2~12 个分离闭环，新单体每层恒 1 个连续闭环。
  形状判据用「同一形状自采样基线」0.0049：新 vs 旧 23 件 = 0.0634（12.9×）、新 vs L9 14 件 = 0.0389（8.2×）；单位陷阱修正（04 网格毫米口径 Z=100，新模型归一化 Z=1.012）。
  结论：13 链条的 loose-parts 分离套到新模型只会得 1 件；新单体才是 L9 画线分割的正确输入。
- **L19 平面链路**：×100 毫米口径与 L9 同尺度、不改算法系数；焊接顶点取 89,954 面 LOD 代理（体积误差 0.088%，99.517% 面心映射 <1 mm）；`seam_draw_new.html` 7.22 MB，几何解码自检 13/13、Edge 无头 selftest 通过。9.65° 斜向闭环割线（399 面，PCA RMS 0.002 mm）→ 半空间布尔 EXACT 10.4/10.5 s → 两件 STL → 11/11 独立复验全过（水密、各 1 连通块、体积误差 6.23e-6、bbox 7.17e-6 mm）。装配面 6/6：746.43 vs 742.30 mm²、法向 ±0.999995、平面度 2.9e-6 mm。两个真坑：STL triangle soup 未焊接会碎成 3~5 万块；二进制 STL header 必须严格 80 字节。
- **L19 曲面链路**：平面分支只吃共面闭环，补曲面分支。抛物面割线共面 RMS 0.6701 mm，被平面流水线拒收；v1 径向环自交失败（5 条非流形边 / 5 连通块，失败证据保留）；v2 改 2D Delaunay 高度场膜（822 三角形 + 侧壁/顶盖），cutter 491 顶点 / 978 面 / 水密。`l19_pipeline_curved.py` 端到端 SUCCESS 10/10：布尔 5.92 s、复验 44.22 s、体积误差 2.97e-10、切面 z 跨度 3.06 mm。
- **L19 统一入口**：`l19_pipeline_auto.py` 三路实跑通过（共面 SUCCESS 88.77 s / 非共面 SUCCESS 54.03 s / 未闭合 REJECTED）。剩余边界：自相交环、垂直回折环未验证；L9 面带分离未接入；路由判据目前只看共面 RMS。
