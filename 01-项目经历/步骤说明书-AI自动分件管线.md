# AI 自动分件步骤说明书（v1 规划版）

> **适用场景**：在**已有 3D 模型**（AIGC 图生 3D / 扫描 / CAD 导出）基础上，AI 自动拆割成若干小件。
> **两个硬约束**：① 拆线**隐蔽**（不破坏外观，尽量沿部件交界 / 自遮挡区）；② 连接**方便**（切口可装配，带定位/连接结构）。
> **本文档定位**：规划版，不含代码。每步给出「输入 / 产出 / 关键算法 / 验收标准 / 与现有方法差异」，可直接作为执行清单。
> **与已有工作关系**：几何代价场（可见性+凹度）已被 Chopper 2012、Disney 专利覆盖；本文档的增量落在 **语义层（PartField 自动出禁切区）** 与 **连接设计层（隐蔽切 + 平底面约束的混合切）** 两块——不要重造已有功能。

|---|---|
| **输入规格** | 模型格式（GLB/OBJ/STL）、是否带贴图、典型面数、是否已知有破洞 |
| **输出规格** | 每件一个 GLB + 连接件孔位/凸台 + 一份装配说明（哪件接哪件、方向、连接件清单） |
| **要消灭的失败** | 例：「人工决定切位耗时，且常切在显眼面/脸上 → 目标：自动给出隐蔽且可装配的切位」 |

## 1. 总流程管线（8 步）

```
[已有模型] 
   │
   ▼ Step1 入厂质检  ──(真破洞?)──► Step1b 网格修复（仅必要时）
   ▼ Step2 语义感知  ── PartField 出 part_id + 部件边界环
   ▼ Step3 切割代价场 ── 可见性 + 凹度 + 语义项 → cut_cost
   ▼ Step4 切割决策* ── 对偶图 min-cut（核心）
   ▼ Step5 连接设计* ── 布连接件 + 平底面约束（隐蔽∩方便的关键）
   ▼ Step6 封盖校验 ── 水密 / 体积 / 可平放
   ▼ Step7 导出装配 ── 每件 GLB + 装配说明
   ▼ Step8 评估对照 ── cut_cost / 干涉 / 对比基线
```
带 `*` 为本文档相对已有方法的新增增量层。

## 2. 分步详解

### Step 0 · 立项与规格
- **输入**：第 0 节填好的四张表。
- **产出**：`project_spec.md`（一份，钉死范围）。
- **验收**：能一句话说清「把 X 指标从 A 降到 B，对照 C」。

### Step 1 · 入厂质检（Mesh Intake）
- **输入**：原始模型文件。
- **关键算法**：
  - `trimesh` 加载后 `merge_vertices(merge_tex=True, merge_norm=True)` 焊合（默认 merge 在 UV 接缝处会失败，必须带这两个参数）。
  - 测 `is_watertight`、`boundary_edges`、体积。
- **产出**：`mesh_health.json`（watertight? 边界边数? 真破洞 or 仅 UV 缝?）。
- **验收**：能区分「真破洞」（需修复）与「UV 接缝」（假破洞，不用修）。
- **与现有差异**：无；纯工具步骤。
- **第 1b 步（仅必要时）**：若确认真破洞，走网格修复支路（我们此前样本 astronaut_kid 实测 watertight、0 真破洞，12 万「开放边」全是 UV 缝 → 该样本可跳过修复）。**只有更差的样本（如 TRELLIS 破网格）才需要**。

### Step 2 · 语义感知（Semantic Perception）★增量前提
- **输入**：Step1 焊合后的网格 + 是否带贴图。
- **关键算法**：
  - 无贴图 → **PartField**（前馈部件特征场，mIoU≈79.18，直接吃 AI 生成网格）或 SegmentAnyMesh（保险）。
  - 有贴图 → MeshSeg。
  - 输出**逐面/逐顶点 part_id** 与**部件边界环**（即候选缝位置）。
- **产出**：`part_labels.json` + `part_boundary_loops.json`。
- **验收**：主要部件（头/躯干/四肢）标签正确，边界环闭合连续。
- **与现有差异**：PartField 只出标签、不管切；Orca/Disney 的禁切区靠人手涂。**用 PartField 边界自动生成禁切区，是本文档第一个增量。**

### Step 3 · 切割代价场（Cut Cost Field）
- **输入**：网格 + Step2 的 part_id。
- **关键算法**（每顶点一个标量 cut_cost）：
  - 可见性项 `vis`：环境光遮蔽 / 自遮挡代理（越自遮挡越便宜）。
  - 凹度项 `conc`：顶点 umbrella 离散平均曲率 `umbrella = V - avg(邻居)`，`vconc = clip(-(umbrella·vn), 0, ∞)`，归一化。
  - 语义项：跨部件边（label 不同）减价，把缝吸在部件边界；高显著部件（脸/盔面）设为硬禁切区（权重→∞）。
  - 合成：`cut_cost = 0.35*vis + 0.65*(1-conc)`，再按 p2/p98 分位数拉伸。
- **产出**：`cut_cost.npz`（逐顶点）+ 着色 GLB（仅内部调试/汇报用，**不进论文正文**，避免像 Chopper Figure 10）。
- **验收**：腰部/靴子/背包偏蓝，胸口/脸偏红；纯蓝占比 >1%（此前饱和 bug 修后约 1.3%→24%）。

### Step 4 · 切割决策：对偶图 min-cut ★核心增量
- **输入**：Step3 的 cut_cost + Step2 的 part_id + 种子（每部件离边界最远的面）。
- **关键算法**：
  - 构造**对偶图**：每个面 = 节点，相邻面之间 = 边。
  - 边权 `w(e) = 0.5*(c(f1)+c(f2))   // 已有的 cut_cost`  
           `− λ1*[label(f1)≠label(f2)] // 跨语义部件→减价，吸在边界`  
           `＋ λ2*[e∈禁切区]          // 硬禁切，等价于 ∞`
  - 对种子间做 **min-cut**（PyMaxflow / networkx），自动求总权最小的闭合割线。
  - **平面切只是此处的特例**（加共面约束）；本文档默认用自由 cut，可绕背/从腋下穿。
- **产出**：`cut_loops.json`（闭合割线）+ 该割线平均 `c̄`。
- **验收（最小可证伪）**：`c̄ < 0.4` 且显著低于水平切 0.764 → 方法成立，可扩到多件。若不低 → 改的是代价函数（Step3），不是切法。

### Step 5 · 连接设计（Connection Design）★用户重点：连接方便
- **输入**：Step4 割线 + 模型几何。
- **关键算法**：
  - **混合切约束**：割线大部分自由（绕开脸，保隐蔽）；在需放连接件的区段**强制落在局部拟合平面上**（平底面），给每件留可平放的小基面。形式化为「min-cut + 局部平面约束」。
  - **连接件放置**：在割线两侧采样候选点 → 检查两侧是否有足够平面基面面积与净空 → 用贪心/模拟退火选最少数量满足装配约束（定位销 dowel / 磁吸 socket / 卡扣 snap-fit / 燕尾 dovetail）。
  - **连接可行性作为代价项**（对应 Disney 专利 `ƒ_connector`）：把「该处能否放连接件」并入边权，使 min-cut 自动避开无法装配的区域。
- **产出**：`connectors.json`（位置/类型/朝向）+ 修改后的割线（带平底面段）。
- **验收**：每件至少有一个定位基准；连接件 100% 通过干涉检查；平底面占比满足打印/装配需求。

### Step 6 · 封盖与可制造性校验
- **输入**：Step5 割线 + 原网格。
- **关键算法**：
  - 平面环：`trimesh.slice_mesh_plane(mesh, plane_normal, plane_origin, cap=True)`（需 shapely，已验证可用）。
  - 非平面环：取边界环 → 投影到最佳拟合平面做 2D 约束三角化反投影（大曲率失真）/ 或 Poisson 薄板重建极小曲面（稳但慢）。**这是全流程唯一真难点，审稿人必问。**
  - 校验：`is_watertight`、体积、可平放性（底面法向接近世界 up）。
- **产出**：`part_top.glb` / `part_bottom.glb` …（每件水密）。
- **验收**：每件 watertight、体积合理、可平放。

### Step 7 · 导出与装配说明
- **输入**：Step6 各件 + Step5 连接件。
- **产出**：每件 GLB（含孔位/凸台）+ `assembly.md`（哪件接哪件、方向、连接件清单、打印/装配顺序）。
- **验收**：第三方打开任一件即可 3D 打印或数字装配。

### Step 8 · 评估与对照
- **隐蔽性**：割线平均 cut_cost（目标 < 0.4 vs 基线 0.764）；切口 AO 值。
- **连接方便**：连接件数量、干涉检查通过率、平底面占比。
- **对照**：vs Chopper（软惩罚）、Disney（硬禁切人手涂）、平面切手动；列表说明本文档在「语义自动禁切 + 隐蔽∩方便混合切」上的差异。

## 3. 必须正视的三个张力（仔细推敲）

1. **隐蔽 vs 平放/连接**（最核心）
   非平面自由切最隐蔽，但切面是麻花面、立不住、难放连接件；平面切好连接但必穿正面（0.764）。
   → 解法：**混合切**（Step5）——自由段保隐蔽，关键段强制平底面保连接。这是可写进论文的贡献点，不是工程补丁。

2. **语义边界 vs 几何凹度**
   PartField 边界不一定落在最隐蔽处（可能在显眼面上）。
   → 解法：Step3 把语义项设为「减价 + 禁切区」而非「硬选」，让几何代价场做最终仲裁。

3. **全自动 vs 可控**
   纯自动可能出怪切法。
   → 解法：禁切区/种子允许人工增删（承接 IP 2018 的人手涂抹，但默认由 PartField 预填），人只在边界情形介入。

## 5. 最小可证伪实验（建议第一步就做，1–2 小时）

只切一刀（头/躯干），比较：
- `min-cut 割线平均 c̄` vs `水平切 0.764`

**若 c̄ 显著 < 0.4** → 管线成立，按 Step1→8 推进。
**若 c̄ 不低** → 问题在 Step3 代价函数（可见性项饱和 / 语义项权重），先调代价场再回来。
此实验一次性回答「切法到底行不行」，比再讨论十篇论文有用。
