# 目标域样本标注规范（一页纸）

> 2026-11-11。配合 `标注工具/annotate_server.py` 使用。
> 目的：把「用户收集的 AIGC 人形/手办单网格」变成 `(整体 mesh, per-face 部位标签)`
> ——目标域集的领域尺子。指标口径先行：**只叫「与这套标注的一致度」，不叫语义正确率**
> （L8 已被证伪：分割粒度没有唯一正确答案）。

## 0. 标注前体检（不过体检不标注）

| 检查 | 判据 | 不过怎么办 |
|---|---|---|
| 单壳 | 连通块 == 1 | 拒收（登记为负向样本） |
| 单位 | bbox 最大边 50~600mm（人形/手办典型） | 换算成 mm 再标；换算依据记进 meta |
| 面数 | 记录实际值；整数万级为正常 | — |
| 水密 | 记录是否水密 | 非水密可标（表面标签不依赖水密），但要在 meta 记 |

体检命令：`python 标注工具/annotate_server.py --check 模型.stl`

## 1. 部位词表（固定 20 类，新增要改这份文档）

`head`（头） `hair`（头发，与头分件时单列） `face`（五官区，仅当明显可分区）
`neck` `body`（躯干） `arm_l` `arm_r` `hand_l` `hand_r`
`leg_l` `leg_r` `foot_l` `foot_r` `skirt`（裙/摆） `tail`
`backpack`（背包） `weapon`（手持物） `wing`（翼） `base`（底座/支架）
`other`（确实无法归入上面任何一类的残余；**用了 other 要在 meta 说明**）

铁律：**不猜**。一个面属于什么部位有疑义时，标 `UNKNOWN`（工具支持），
由人工仲裁后回填——UNKNOWN 是诚实，猜一个是污染。

## 2. 边界口径

- 边界优先落在**测地脊线**（部件转折处）或**法向突变带**（工具默认按此生长）；
- 连体/穿插结构（如袖子与躯干相连）：按「打印时分得开」的最低部位分，
  即沿实际可切缝走，不按解剖学强行分；
- 同一部位被非流形缝分开的（AIGC 常见）：如果两段几何连续、语义同一，
  允许同一标签覆盖不相邻的两块，meta 里记 `disjoint: true`；
- 粒度参照 MakerWorld 词表结论（真实设计师粒度：「嘴巴单切、衣服按色切」），
  但**目标域分布是 AIGC 光滑单网格，不照搬打印件的粒度**——
  拿不准时按「这件打印出来能不能单独拆、单独上色」判。

## 3. 标注流程

1. 体检（§0）→ 2. 起服务、浏览器涂选（§4）→ 3. 逐部位：
   涂种子 → 调生长参数（距离阈值/法向角）→ **看预览确认** → 提交；
   已标面用颜色覆盖显示，漏标处补涂、过标处用橡皮减面
   → 4. 全网格覆盖检查（工具显示未标注面数，必须归零或全是 UNKNOWN）
   → 5. 导出 `labels.json` → 6. 双人交叉：同一模型两人各标一遍，
   一致度 < 0.9 的部位进仲裁清单（将来用 segmetrics 的 agreement_matrix 算）。

## 4. 导出格式（labels.json）

```json
{
  "model": "cand-02.stl",
  "sha256": "…",
  "at": "2026-11-11T…",
  "tool": "annotate_server v0.1",
  "params": {"dist_mm": 8.0, "normal_deg": 45.0},
  "labels": {"head": [12, 13, …], "arm_l": […], "UNKNOWN": […]},
  "meta": {"unit": "mm", "components": 1, "faces": 512233,
           "disjoint": ["hair"], "other_note": ""}
}
```

- `labels` 的 value 是面 id 列表（与 trimesh face 序一致）；
- 一个面只能属于一个部位（工具强制，冲突即报错）；
- `UNKNOWN` 是合法标签，不是失败；`other` 要写 note。

## 5. 验收口径（与 18 仓 parts_available 校验器对接）

- 标注产物经 `标注工具/labels_to_npy.py` 转 `face_labels.npy`，
  与 `truth/` 的真值格式对齐，可直接喂 `split3d_verify:parts_available`；
- 指标：per-part IoU / 边界偏差（chamfer）/ 漏分多分件数——
  全部来自 `split3d_segmetrics`，可复算（固定种子采样）；
- 单对比较无分辨力（1 件 vs 1 件恒为 IoU=1）——评估必须在多件矩阵上进行；
- 无标注模型按既定规则拒收，不猜标签。
