# 12 · 交互式画线分割（L9）

**一句话**：人在 3D 模型上画看得见的那一段割线，agent 在对偶图上把两端绕背面连成闭环，
再按这条线把模型真正切成两件并导出 STL/GLB。

> **v2（2026-11-07）**：画线从「按住拖拽逐帧采样」改为**线段式**——单击落点 → 橡皮筋直线 →
> 再单击成段；段沿表面测地路径贴合，每段可拖紫色中点改弧度；新增后台 `refine_seam.py`
> 做平滑加工并复验闭环。完整取舍与实测见 `L9-线段式画线推敲与优化.md`。
> **v1 三种补全的实测数字经复跑逐一吻合**，本次改动没有静默改变已验证的结论。

这是对 L1~L8 的**路线切换**，不是又一轮阈值打磨：

- L6 说「人工真值集要人来标」，L7 说「要直接标边」；
- 这里让人**直接画整条设计意图的割线**，不再需要从几何里猜语义、也不再标零散的边；
- 工具刻意不加载 `cut_cost`、不预测语义、不自动找接缝。割线的正确性来自人，
  agent 只做「闭合 + 执行切割」，且闭环成立与否有可检验的判据。

---

## 怎么用

1. 双击 `seam_draw.html`（单文件离线，7.24 MB，内联 three.js r160 与几何，不联网）。
2. **左键单击**在模型表面落一个锚点；移动鼠标看灰虚线（两点直线，仅示意）与橙线（贴表面预览）；
   **再单击**提交一段。点回起点或按 `Enter` 闭合环；`Ctrl+Z` 撤一点；`Esc` 取消选中。
   右键旋转、滚轮缩放、中键平移。
3. 点中某段的**紫色中点**并拖动，或用侧栏 `bulge` 滑块，给这段调弧度；
   中点会投影回模型表面，弧不会悬空。`bulge=0` 即直线段。
   `弦引导权重 λ` 控制「贴用户所指方向 vs 纯最短测地」，默认 1.2，`λ=0` 退化为纯测地。
4. 选补全策略（默认「沿画线平面」）：
   - **最短**：只按面心距离接驳，容易抄近路穿过正面；
   - **绕背**：偏好背对相机的一侧；
   - **沿画线平面**：从你画的点 PCA 拟合平面，惩罚偏离；画线明显不共面（残差 > 6 mm）时自动退化为最短。
5. 左侧实时显示**闭环判据**：删掉割线经过的面带后，面图必须恰好断成两大块才算切开。
   只画正面半段时通常是 1 块，这就是要 agent 补全的原因。
6. 点「按画线分割」看爆炸预览（蓝 / 橙两件，滑块调间距）；
   点「导出画线 JSON」得到 `my_seam.json`（`seam_draw/v2`，保留 `loop_faces` 契约）。
7. 后台执行（**平滑可选，但会复验闭环**）：
   ```bash
   python refine_seam.py my_seam.json            # 可选：平滑 + 复验闭环 → my_seam_refined.json
   python split_from_drawing.py my_seam_refined.json --cap fan
   # 不想平滑就直接切（v2 JSON 可直接吃）：
   python split_from_drawing.py my_seam.json --cap fan
   ```
   输出 `part_A.stl` / `part_B.stl` / `split_preview.glb` / `split_report.json`。
   不加 `--cap fan` 则导出开放曲面并如实报告边界边数（不假装水密）。
   `refine_seam.py` 在闭环被破坏或偏差超阈值时会**告警并另存**，不覆盖原 JSON。

`?demo=1` 载入 legacy 示例（绿环 = 完整水平切片真值环，黄线 = 只交给人的正面一段，
数字与 v1 一致）；`?v2demo=1` 用 12 个锚点走线段式新链路（看线条顺滑程度）；
`?split=1` 直接看爆炸分割；`?selftest=1` 把交互 / λ / 路径点 / 弧度 / 三种补全的
结果写进 `data-selftest`，并把一份真实 v2 JSON 写进 `data-v2json` 供自动化抓取。

## 实测结果（v1 legacy 口径；v2 复跑数字逐一吻合，见下方 v2 小节）

人只画 219 个面；完整真值环切出的参照结果是 **75,004 / 14,868 面**。

| 补全模式 | 补全面 | 闭环面带 | 切成的小件 | 相对真值偏差 | 小件体积 |
|---|---:|---:|---:|---:|---:|
| 最短 | 90 | 309 | 2,222 面 | **85.1%** | 0.73 cm³ |
| 绕背 | 87 | 306 | 1,874 面 | **87.4%** | 0.66 cm³ |
| **沿画线平面** | **275** | **494** | **15,124 面** | **1.7%** | **22.37 cm³** |
| 真值环（参照） | — | 629 | 14,868 面 | 0% | 22.68 cm³ |

- 画线平面拟合残差 `0.00 mm`（示例是严格水平切片，约束启用）。
- 三种模式**都**让面图断成 2 大块、后台 fan 封盖后两件都水密、无非流形边。
  → 「闭环成立」只证明切开了，**证明不了切对位置**。最差的最短模式同样分出 2 块，
  但小件只有 0.726 cm³。这与 L7「拓扑验真对系统性错位不敏感」一致。
- 前端分块面数与后台 `split_report.json` **严格一致**（同口径：含回分配的带面）。

### v2 线段式 / 平滑（2026-11-07 实测）

样例为 demo 轮廓降采样成 **12 锚点 / 11 段**（不是用户真实手绘），
三条折线统一重采样 `ds=0.6 mm` 后比较，详见 `L9-线段式画线推敲与优化.md` 第 7 节：

| 折线 | 转折角 | 弧长 | 相对面心 |
|---|---:|---:|---:|
| 面心（v1 口径） | 6688° | 76.93 mm | — |
| 边中点（v2 线段式） | 4837° | 72.67 mm | −27.7% |
| Taubin 平滑后（iters=8） | 2110° | 65.04 mm | **−68.5%** |

- **改善归因**：`--iters 0`（只重采样+投影）已降 29.7%，Taubin 平滑再贡献 26.7 个百分点，
  不能把 56.4% 全算给平滑。迭代扫描显示 8 次是收益拐点（8→15 只多 1.1 个百分点、偏差继续涨）。
- **闭环复验真的救了一次**：首版平滑后大块数 **2→1**、55 处断点，脚本按设计告警；
  查到面邻接 CSR 的重复索引赋值 bug，修好后断点 0、大块 2→2、抽样 2000/2000 邻接正确。
- 端到端：原始 v2 与 refined 都切出 2 大块，A 73,899→73,896 面、B 16,086→16,088 面，
  体积 23.874→23.835 cm³ —— 平滑让线更顺但**没有偷偷改变切分结果**。
  如实保留硬伤：`part_A` 仍有 1 条非流形边、不水密（原带回分配链路的已知问题，本轮未修）。
- 真实 `PointerEvent` 自检：两次单击 → 2 锚点 / 1 段 / 38 面，弦长 8.862 mm、测地长 11.746 mm。

## 关于「打印」——一个实测出来的坑

另见 `../11-分件打印交付包/assembly_check.json`（上一轮实测）：
那 14 个规则分件 STL 全部水密、无非流形，是沿原始网格法向**加厚 1.2 mm 的薄壳**；
19 对分界面中位间隙只有 **0.119 mm**（范围 0.074~0.204 mm），11 对存在明显互相内侵（最高 29.4%）。

结论：**按 1:1 打印出来会顶死，不是可直接插装的套件**。要能装，必须在分件阶段给配合面做
单侧 0.15~0.25 mm 偏置（或缩一件 / 放另一件），并补定位榫与装配顺序。

本工具导出的两件同样是从同一张连续表面切出、各自封盖，配合面零间隙，
所以同样需要这一步；`split_report.json` 只报告几何水密性，**不评判可装配性**。

## 口径与限定

- 绿环是**水平切片构造**的几何真值，不是人工设计师手绘的藏缝意图；
  用它验证的是「补全能不能复原一条已知闭环」，不是「这条缝好不好」。
- 平面约束是纯几何外推（PCA + 偏离惩罚），不含任何语义 / 代价场 / 学习模型；
  对非共面的自由曲线会自动退化，此时建议**转视角多画几段**，让 agent 只做短距离接驳。
- 补全路径越长越不可信。工具显示补全面数与闭环面带长度，就是让人能判断这一点。
- fan 封盖是边界环质心扇形三角化，凹陷环可能自交；水密性与绕序一致性在报告里如实给出。
- 分割只按面邻接执行，**不评判缝的语义合理性、可装配性、可打印性**。
  下游要能装，仍需配合面偏置与真实装配实测。
- **灰虚线（两点直线）只是示意，后台切的是黄色表面路径**：曲面上两点的空间弦一般不在表面上，
  工具把两者同屏显示并给出弦长 / 测地长，避免「显示的证据」与「执行的数据」不一致。
- **弦引导 λ 有代价**：λ 越大越贴用户所指方向、越不绕背，实测最大偏离弦 2.499→1.586 mm，
  但转折角 9746→11016°（路径更碎）。它是显式旋钮，不是藏起来的超参。
- **平滑只改形状、不改设计意图**：`anchors` / `bulge` 不动，agent 补全段不平滑；
  平滑后必须用同口径 `connected_components` 复验闭环（首版实测真的把 2 大块弄成 1 块）。
- v2 自检样例是 demo 轮廓降采样成 12 个锚点，**不是用户真实手绘**；
  「人工画出来」仍是用户动作，agent 不替用户产生设计意图。
