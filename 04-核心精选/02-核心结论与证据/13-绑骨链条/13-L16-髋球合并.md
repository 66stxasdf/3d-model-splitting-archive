## 1. 用户指令与本轮判定

L15 第 5 节留了三个结构方向：① 右侧补对称球、② 把 `L_JointPin` 合并回相邻件、③ 直接删球。
用户回复「**2 合并它到其他相邻零件上**」，即选 ②。

本轮先做全量引用探测（`l16_probe.py` / `l16_probe.json`），不凭观感动手：

| 项 | `L_JointPin`（球） | `L_Leg`（腿） |
|---|---|---|
| 顶点 / 面 | 8,898 / 17,792 | 49,787 / 99,574 |
| 顶点组 | `L_JointPin`，8,898 点全 1.0 | `L_Leg`，49,787 点全 1.0 |
| 材质 | `MAT_JointBall_Metal`（灰金属） | `L_Leg_M`（绿） |
| 修改器 | `RigidBind` → `PartRig` | `RigidBind` → `PartRig` |
| Collection | `06_JOINT_DETAIL 关节细节`（唯一成员） | `05_LEG_FOOT 腿脚` |
| 骨骼 | `L_JointPin`，父 `L_LegArmor`，**无子节点** | `L_Leg`，父 `L_LegArmor`，子 `L_Foot` |
| 约束 | `L13_LIMIT_L_JointPin` | `L13_LIMIT_L_Leg` |

名字残留引用只有 4 处：球对象本身、隐藏候选 `MIRROR_L_JointPin` 的同名顶点组、
`L15_note` 场景属性、以及那根骨骼。没有动作、驱动、文本块或其它对象引用它。

### 合并目标为什么是 `L_Leg`（`l15_ball_diagnosis.json`）

BVH 球面 400 采样点：

| 邻近件 | 最小距离 | 中位距离 | < 0.02 的点数 |
|---|---|---|---|
| **L_Leg** | **0.000000** | **0.001492** | **400 / 400** |
| L_Hip | 0.002791 | 0.017097 | 239 / 400 |
| CORE_Spine | 0.046442 | 0.069673 | 0 / 400 |

球与腿共形贴合、几乎零间隙，本质是腿上的一层球壳；`L_Hip` 只是局部靠近，
`CORE_Spine` 差一个数量级。**合到 `L_Leg` 是几何事实决定的，不是就近随手挑的。**

## 2. 合并真正修好的问题（本轮核心发现）

`L_JointPin` 与 `L_Leg` **同挂 `L_LegArmor`，是兄弟叶骨**。
L13/v4 解耦层级时把腰腿链改挂躯干，解决了「抬肩带动整条腿」，但没处理这层兄弟关系：

> 摆 `L_Leg` 时，腿动，球**不动** —— 球会当场从腿的球座里脱开。

这是 L15 只改颜色没暴露、只有摆姿势才暴露的结构错误。用评估网格顶点位移实测
（`l16_pose_evidence.json`，摆 `L_Leg` 绕 X 轴 30°，在 ±60° 约束内）：

| 指标 | v6（合并前） | v7（合并后） |
|---|---|---|
| 球最大位移 | **0.000000**（原地不动） | **0.064288**（随腿走） |
| 腿最大位移 | 0.066893 | 0.066893 |
| 球↔腿中位间隙 rest | 0.001833 | 0.001833 |
| 球↔腿中位间隙 posed | **0.022976**（炸开 12.5×） | **0.001833**（保持） |
| 跨件点对距离最大变化 | 0.061630 | **4.07e-08**（同一刚体变换，保距） |

沿用 L13 的教训：**判据用评估网格顶点位移，不看 `matrix_basis`**（约束会让它说谎）。

## 3. 合并口径：结构合并，不是布尔融合

`Ctrl+J` 式 `object.join`，**源几何一片面都没删、没焊接、没重拓扑**。球仍是球，
只是不再是「独立对象 / 独立骨骼 / 独立约束」。这样既不丢源 STL 几何，又能在装配意义上算一件。

`build_v7.py` 六个动作：

| # | 动作 | 防护 |
|---|---|---|
| 1 | 球网格并入 `L_Leg`（active） | 断言顶点/面数 = 两者之和；清理 join 可能带进来的第二个 Armature 修改器，防双重变形 |
| 2 | 球顶点权重 `L_JointPin` 组 → `L_Leg` 组，删空组 | 按顶点组反查球顶点（不硬编码索引）；断言 58,685 顶点全在唯一组、权重恒 1.0 |
| 3 | 球材质保留为**第 2 材质槽** | 断言 `material_index == 1` 的面恰为 17,792；关节球颜色不变、仍可辨识 |
| 4 | 删叶骨 `L_JointPin` 及其 `LIMIT_ROTATION` | 断言父为 `L_LegArmor` 且无子节点；删后逐骨比对 `matrix_local`/head/tail/parent，偏差 0.0 |
| 5 | 隐藏候选 `MIRROR_L_JointPin` 的同名顶点组改名 `R_Leg` | 消除悬空骨骼引用；几何不动、仍全隐藏（选项 1 已否决，素材留着） |
| 6 | 移除空的 `06_JOINT_DETAIL` 集合、写 `L16_*` 语义属性与 scene 说明 | v6 不覆盖，另存 v7 |

球顶点世界坐标最大漂移 **1.49e-08**，球心偏差 **1.62e-08**。

## 6. 边界与没做的（如实留痕）

1. **球几何与金属材质零损失**：8,898 v / 17,792 f 与 `MAT_JointBall_Metal` 都在，
   球心偏差 1.62e-08。删掉的只是「独立零件 / 独立骨 / 独立约束」这层身份。
2. **第 2 材质槽让关节球仍可辨识**（灰金属，与绿色腿不同色）。若希望视觉上也完全融进腿色，
   把 17,792 个面的 `material_index` 从 1 改 0 即可，说一声就改。
3. **右侧仍缺对称球**：`MIRROR_L_JointPin` 候选保留但默认隐藏（选项 1 已被否决），
   其顶点组已改名 `R_Leg` 以免悬空；未绑定骨架。
4. **未重跑 rest 固有互穿统计**：历史「18 对」口径里若包含球↔腿，合并后该对不再跨对象，
   这个数字需要重算才有意义，本轮没动。
5. **只改 `.blend` 工程**：`parts_rigged.glb`、23 个 `part_*.stl`、`manifest.json`、
   查看器与 L1~L15 的历史文档仍描述 23 件口径，未同步，避免把整条链的编号口径一次性搅乱。
6. 单位仍未知；其余 3 个孤件红色高亮、分色线几何锯齿、其余贴合对互穿都还在。
7. **全部本地产物，未执行任何资产库写操作。**
