# L12 · v2 结构优化：细节分层与装配逻辑

日期：2026-11-08 晚　｜　基线：`parts_fixed.blend`（L11 穿模修复后）
用户指令：**「先不打印，先把模型建好，要求细节分，结构符合逻辑，继续优化」**

我对「细节分」的执行口径：**按功能把零件分出细节层级、让左右对称与父子关系可读**。
本轮**零几何变更**——不增面、不减面、不改一个顶点，因此「细节丰富度」本身没有提升；
如果是要「加倒角/凸筋/铆钉等新细节」，那是另一条建模链路，见文末待确认项。

## 一、先审计，不动手

`audit_structure.py` 在修复版 23 件上重算了全量镜像度量（253 对，每件 3000 表面采样点、
双向 Chamfer），并把旧 MST 骨架树打印出来：

| 发现 | 数字 |
|---|---|
| AABB 重叠对 | 56 |
| 疑似对称对 | 22 |
| **其中父节点不一致** | **16 对**（例如 `J_00←J_04` 但对称件 `J_01←J_13`） |
| MST 根 | `J_13`，直接挂 11 个孩子 |

也就是说：按「谁离谁近」推断的 MST 层级，把左右对称件挂到了**互不相关的父节点**下，
单独拖动一侧时会不同步——这就是「结构不符合逻辑」最硬的一条证据。

`match_pairs.py` 用**带硬约束的互最佳贪心**（左右分居 / 同高 / 镜像必须显著优于直接比较 /
允许不配对）把配对定死：

- **8 组左右对称对**：肩甲、翼、胸侧装甲、腰侧、髋甲、腿甲、小腿、脚
  （2 perfect、3 good、3 fair；残差 0.0229 ~ 0.1545）
- **3 个中线核心件**：躯干 `part_13`、头 `part_14`、中轴 `part_20`
- **4 个缺对称伙伴的孤件**：`part_04` / `part_05` / `part_21` / `part_22`

## 二、实施了什么

`build_v2.py` 从 `parts_fixed.blend` 派生 **`parts_v2.blend`**，原工程不覆盖：

1. **语义命名**：`part_XX / J_XX` → `CORE_Torso`、`L_Shoulder`、`R_Foot`、
   `R_ShoulderDetail` …，23 件与 23 根骨一一对应。
2. **骨架层级重建**：root = `CORE_Torso`；左右各一条
   `Shoulder → ChestPanel → WaistSide → Hip → LegArmor → Leg → Foot` 链，
   双翼单独挂躯干，孤件挂同侧最近父。层级树本身左右镜像一致。
   改 parent 前记录每根骨的 head/tail/roll，改完原样写回，**rest pose 不变**。
3. **细节分层**：建 7 个 Collection（核心 / 头肩 / 翼 / 胸侧 / 腰髋 / 腿脚 / 关节细节）。
4. **分组配色**：左右对同色（一眼看出对称），核心金、肩橙、翼紫、胸腰蓝、腿脚绿；
   **4 个孤件统一红色高亮**（一眼看出结构缺口）。
5. 顶点组按新骨名重建为 100% 刚性权重，Armature modifier 全部保留。

## 三、复验（`verify_v2.py` 跨文件逐件比对）

| 判据 | 结果 |
|---|---|
| 世界包围盒最大偏差 | **0.0** |
| 面数 / 顶点数 | 1,680,611 面，23/23 完全一致 |
| 骨骼 head/tail 最大偏差（rest pose） | **0.0** |
| 层级与设计一致 | True，root 唯一 = `CORE_Torso` |
| 每物体 1 个顶点组且名字符合 / Armature modifier | True / True |
| **对称对父节点左右镜像一致** | **8 / 8**（原 MST 只有 6 / 22 勉强同父） |

结论：**结构改了，几何和绑定姿态一点没动**，导入即变形的风险被排除。

## 四、本轮被证伪 / 修掉的坑（保留留痕）

1. **无约束 Hungarian 把中线躯干配给了侧件**（`12-13`，镜像反而比直接差 0.53×）。
   算法最优 ≠ 结构合理，改成带硬约束且允许不配对的互最佳贪心。
2. **翼被误插进肩→胸的父子链**（`L_ChestPanel ← L_Wing`）：建链时把 `Wing` 也遍历进去了。
   复验脚本抓出后排除，重跑才得到 8/8 镜像一致。
3. **镜像一致性判据把左右方向写反**，误报 7/8；改成去 `L_`/`R_` 前缀比基准名。
4. **渲染全白**：Blender 中文界面节点叫「原理化 BSDF」，脚本按 `Principled BSDF`
   按名查找返回空，Base Color 没写进去；改为按 `node.type` 查找。
5. **AgX + 原场景强灯光过曝**，分组色被压成浅白；可视化改用 Workbench + 材质色，
   不依赖灯光/节点。
6. **相机只拉远没重设朝向**，模型偏出画面；改成正交相机对准包围盒中心，
   `ortho_scale = diag × 1.22`，全身完整入镜。

## 五、边界与如实交代

1. **零几何变更**：细节的「数量/丰富度」没变，本轮只解决**组织与逻辑**。
2. **4 个孤件没补**：补齐会新增零件、改变外观，且源模型可能是刻意单侧设计
   （右手持长枪等）。是否镜像补件属于风格决定，留给你确认。
3. **对称残差没修**：8 对里 3 对残差 0.10~0.15（腰侧 0.1434、小腿 0.1036、
   脚 0.1545），源模型左右本不严格一致；强行镜像会改外形。
4. **单位未知**（STL 不含元数据），所有几何数字仍是文件原始坐标。
5. 上一轮 L11 的装配间隙只修了 2 对，其余 54 对贴合未处理；本轮按你的要求暂不打印，
   未继续扩展。
