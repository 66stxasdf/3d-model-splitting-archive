## 1. 判据（先定口径，再看数字）

| 项 | 口径 |
|---|---|
| 穿模判据 | BVH `ray_cast` 奇偶射线，判定表面采样点是否落在**封闭实体内部** |
| 为什么不用 `signed_distance` | 近共面处符号会骗人（L11 已踩过：修复后它报「100% 在内部」，射线判定是 0） |
| 采样 | 每件固定 900 个顶点，**跨姿势复用同一批索引**，消除采样噪声 |
| 观察量 | `total_inside`（互穿采样点）、`new_pairs`（rest 之外新增的穿模对）、零件质心位移 |
| 为什么必须有 rest 基线 | 静止姿态本身就有互穿，姿势让某些件分开会让总量下降，只看总量会把「改善」误判成「恶化」 |

rest 基线：**1657 个互穿采样点、18 对零件互相嵌入**。
这是源 STL 的建模方式（装甲板故意内嵌主体避免露缝）在拆成 23 个独立封闭实体后的必然结果，
L11 只修了最严重的 2 对，**其余贴合对未处理**。本轮不碰它们——那属于装配设计决策，不是骨架问题。

## 2. 三个实测发现

### 2.1 静止姿态不是「干净」的

1657 / 18 对。任何「防穿模」的讨论都必须以这个基线为参照，否则会把固有互穿算到姿势头上。

### 2.2 v2 的骨架层级是错的：抬肩会带动整条腿

v2 把 23 件串成一条链：`CORE_Torso → 肩 → 胸侧 → 腰侧 → 髋 → 腿甲 → 腿 → 脚`。
抬左肩 60°，实测位移（`decouple_verify.json`）：

| 零件 | v2 层级 | v4 层级 |
|---|---|---|
| `L_Shoulder` | 0.010644 | 0.010644 |
| `L_ChestPanel` | 0.157611 | 0.157611（本该随肩动） |
| `L_WaistSide` | 0.200671 | **0.000000** |
| `L_Hip` | 0.250899 | **0.000000** |
| `L_Leg` | 0.415512 | **0.000000** |
| `L_Foot` | 0.571286 | **0.000000** |
| 左腿链平均 | 0.341245 | **0.000000** |

v3 四联图左下格能看到整条腿飞出去，不是渲染错误，是父子关系错误。
**v4 修正**：`L_WaistSide` / `R_WaistSide` 父级改为 `CORE_Torso`，`R_ChestPin` 父级改为 `R_ChestPanel`；
躯干下变成肩链、左右腰腿链、双翼四条并列链。骨骼 head/tail/roll 与 rest 变形偏差均 **0.0**。

### 2.3 左右骨同号角度不等于镜像动作

骨骼局部轴在世界空间同向（局部 X = 前后摆动、Z = 左右外展、Y = 自转）。
镜像动作必须**符号取反**；单骨扫描用同号角度时，一侧撞进躯干、另一侧拉开，
导致「左肩 Z +5° 就 +472，右肩 Z 全程为负」这种假不对称。
因此约束按**正 / 负两个方向分别标定**。

## 3. 约束怎么定出来的

`pose_scan_signed.py`：23 骨 × 3 轴 × 2 方向，X/Z 各 7 档（5~60°）、Y 3 档（10/30/60°），
共约 780 次姿势测量，每次都重算 23 件 BVH 与互穿。

- 越限判据：互穿增量 > `82`（rest 的 5%）。`new_pairs` 只记录不作硬判据——
  rest 已有 18 对互穿，微小旋转产生 1~2 对新接触不代表装配崩坏，且该计数对近共面抖动过敏。
- 结果写入 23 个 `LIMIT_ROTATION` 约束（`owner_space=LOCAL`，可整体 `mute` 切换自由摆姿模式）：
  **严格档完全锁死 6 / 69 个「骨×轴」**，宽松档（15% 容差）**0 / 69 锁死**。
- 典型非对称限制：`R_Shoulder X +0° / -60°`——危险方向禁止、安全方向放开，
  比「一刀切 ±10°」既安全又保留可动性。
- 每根骨另存 `L13_loose_limits_json` 自定义属性（15% 档角度），供按需放宽。

**层级一改，单骨带动的子树就变了，所以 v3 的约束数据全部作废**，v4 重新标定了一遍
（v3 锁死 4 个轴，v4 锁死 6 个；多出的两个是左右肩 Z）。

## 4. 两级收益（同一 60° 前后摆臂输入）

| 阶段 | 互穿总数 | 相对 rest 增量 | 新增穿模对 | 最大零件位移 |
|---|---|---|---|---|
| v3 层级 · 无约束 | 5483 | **+3826** | 12 | 0.589 |
| v4 层级 · 约束关闭 | 3529 | **+1872** | 6 | 0.213 |
| v4 层级 · 约束开启 | 1691 | **+34** | 2 | 0.055 |

- **只修层级**：最坏穿模增量 −51%（腿不再被带着乱撞）。
- **再加约束**：相对最初 −99.1%，相对 v4 无约束 −98.2%。
- `combo_70`（肩+翼+腿同时 70°）：约束开 +53 / 关 +85，位移 0.158 / 0.291——
  说明约束是**选择性钳制**，没有把骨架锁死，安全方向仍能大幅运动。

## 5. 补齐 / 对称化候选：只量化，不启用

10 个候选对象放在 `07_CANDIDATES 候选（默认隐藏）` Collection，全部 `hide_render` + `hide_viewport`，
网格经 bmesh 复验边界边与非流形边均为 0（翻转了三角绕序以保证镜像后法线朝外）。

| 候选 | 碰撞代价 | 关键判读 |
|---|---|---|
| `MIRROR_L_JointPin` | 嵌入 0 点 | **最干净**，可考虑启用 |
| `MIRROR_R_FootDetail` | 嵌入 17 点 | 轻微 |
| `MIRROR_R_ChestPin` | 嵌入 199 点 | 与 `L_WaistSide` 双向距离仅 **0.0077**，近乎重复几何 |
| `MIRROR_R_ShoulderDetail` | 嵌入 272 点 | 与 `L_Shoulder` 距离 **0.0161**，疑似与本侧件粘连 |
| 对称替换 `06↔10`（Leg） | 互穿 0 | 残差 0.1036 → 0.0350 |
| 对称替换 `09↔11`（Foot） | 互穿 0 | 残差 0.1545 → 0.0403 |
| 对称替换 `03↔12`（WaistSide） | 互穿 198 | 残差 0.1434 → 0.0634，代价高 |

**结论：4 个「孤件」里有 2 个不像真缺件**，更像源模型拆分时与对侧件粘连，
盲目镜像补齐会造出重复几何——正是之前「形状相同会穿模」那类问题。
所以候选一律默认关闭，是否启用交给风格判断。

## 7. 本轮踩过的坑（都留了痕）

1. **姿势名被当成关节族**：20 个「姿势」其实全是 rest，位移 0，数字波动只是采样噪声。
   修：标签与关节族分开、加「非 rest 必须产生位移」硬断言。
2. **每轮重新随机采样**：±5% 噪声淹没真实变化。修：跨姿势复用同一批顶点索引。
3. **左右同号角度**：见 §2.3。修：正负双向扫描，产出非对称 min/max。
4. **`matrix_basis` 不是约束判据**：`LIMIT_ROTATION` 在求值链后段生效，
   `matrix_basis` 仍显示 60°；用顶点位移验证 60° 输入被精确钳到 10°（与显式 10° 距离 0.0）。
5. **`signed_distance` 符号陷阱**：延续 L11 教训，全程只用奇偶射线。
6. **信息图自己写错数字**：锁定轴数写死成 v3 的 4（v4 是 6）、Y 轴档数写成 7、
   典型限制举了旧值、增量与总量口径混用——已全部改成从 JSON 动态计算并重新出图。

## 8. 如实交代边界与代价

- **没有新增任何细节**（没加倒角 / 凸筋 / 铆钉）。本轮是结构与约束优化，
  「细节丰富度」仍未提升，这是下一轮真正的硬活。
- **rest 固有 18 对互穿仍在**。要彻底解决得重新设计装配关系（退让 + 卡扣），
  不是布尔切一切了事；L11 已证明全量切会削掉 32%~41% 体积、失去嵌入定位。
- **单位仍未知**，0.0006 那类退让值的物理含义待定。
- 候选对象**没有绑定骨架**（它们对应的镜像骨不存在），只作静态参考。
- 源 STL 几何未改；本轮全部产物在本地，**没有做任何资产库写操作**。
