## 0 为什么选这条，不选另外三条

上一轮（L13）给出的下一步是四条：宽松档约束预设 / 启用 3 个 0 互穿候选 / 真加细节 / rest 装配重设计。

| 候选 | 判断 |
|---|---|
| rest 装配重设计 | **直接出局**。它本质是打印装配间隙，与「先不打印」冲突 |
| 宽松档约束预设 | 纯配置，用户看不到任何外观变化，随时能补 |
| 启用 3 个 0 互穿候选 | 能看到橙色新件，但候选未绑骨架，且会引出「重复几何」争议，增益中低 |
| **真加细节** | 命中「细节分」这条一直未被正面回答的主线；前四轮全是骨架组织与约束、零顶点改动 |

已被证伪的是 **全局 Bevel / 全局 Taubin**，不是「按二面角选边的局部细节」。所以先做量化审计再决定怎么做，避免重蹈 R4 覆辙。

## 1 审计：几何本来就很平滑，问题不在「棱角」

`analyze_edges.py` 对 `parts_v2_baseline/` 的 23 件（焊接顶点后）统计面邻接：

| 指标 | 实测 |
|---|---|
| 面邻接边总数 | **2,527,731** |
| 二面角 p50 / p95 / p99 | **2.38° / 19.56° / 40.59°** |
| >30° 真锐边 | 52,820（**2.09%**） |
| >45° / >60° | 18,907（0.75%） / 8,363（0.33%） |
| >30° 连续锐边链 | **11,017** 条，其中 898 条 ≥10 边，最长 890 边 |
| 边长 p1 / p50 / p95 / p99 | 0.00023072 / 0.00104349 / 0.00421719 / 0.00855640 |

结论：用户看到的「满是尖锐棱角」不是几何二面角造成的（L10 已定位为显示链路 + 颜色硬标签边界）；但确实存在**成体系的连续装甲棱线**，可以沿它做真实的结构细节。

### R4 失败的机制解释（本轮补上的证据）

`clamp_overlap` 把倒角宽度钳到邻域最短边的量级。实测：

| width | 比它更短的边占比（会被钳） |
|---|---|
| 0.0002 | 0.49% |
| 0.0006 | **22.80%** |
| 0.0010 | 47.86% |
| 0.0020 | 78.39% |
| 0.0040 | 94.38% |

这解释了 L10 里「三档 Bevel 宽度结果相同」：在极密三角网格上做**全局**倒角，宽度全被 p1≈0.00023 钳住。

| `L_Wing` >30° 锐边 | 8,874 | 3,896 | 3,896 | 3,896 | 3,896 | **25,096** |

## 3 换路线：两个可开关的独立层

### A. 结构加强筋（真实新增几何细节）

- 从每件 >25° 的连续锐边链提取路径（`MIN_CHAIN=14`，`build_v5d.py::sharp_paths`）
- **显式构造封闭圆管**：每点一个 6 边环（法平面由切线构造），相邻环连成四边形带，两端扇形封盖；所有顶点共享 → 天然 watertight
- 沿链生成，故贴合原棱线；管半径 0.0038（约 3.6× 边长中位）
- 亮金 + 自发光 0.45，保证阴影侧也读得出来
- 按件放到 `08_DETAIL 结构加强筋（可开关）`，**逐件刚性绑定到对应骨骼**（顶点组全权重 1.0 + `ARMATURE` 修改器），摆姿势会跟着动
- 最终 21 个对象、616 条链、89,202 个新面

### B. 分色边界柔化（shader 层，零顶点改动）

共享节点组 `NG_L14_EdgeSoft` 插在 23 个主件材质的 `Base Color` 前：

```
Fresnel(IOR 1.45) → MapRange(0.04..0.62) → × SOFT_STRENGTH → Mix(原色, 暗色) → Base Color
```

`SOFT_STRENGTH` 是组内一个 `Value` 节点，因为 23 个材质共享同一个节点组 datablock，**改一次即可全局 0/1 开关**。
作用是把零件轮廓处 1px 的硬颜色切换包进一圈柔和暗边，视觉上成为「有厚度的接缝」。

> 注意：WORKBENCH 不跑 shader 节点，所以柔化只在 Eevee / 材质预览 / 渲染里可见。视口默认 SOLID 看到的是加强筋。

## 4 四轮迭代：每次反思后改了什么

所有像素指标在同一 Eevee 口径（`Standard`、灯光 ×0.10、正交相机 `ortho=0.41975`、800×800）下测得；R1 专门用 `render_v5_r1align.py` 按 R2 的相机重渲染，避免口径漂移。

| 轮次 | 锐角 | 最小链 | 管径 | 链数 | 新增面 | 封闭 | 筋可见像素 | 柔化改变像素 | `>180` 硬跳变 |
|---|---|---|---|---|---|---|---|---|---|
| R1 `v5` | 30° | 16 | 0.0013 | 208 | 53,984 | ✗ | 1,636 | 46,594 | 819→416 (−49.2%) |
| R2 `v5b` | 25° | 12 | 0.0030 | 910 | 147,852 | ✗ | 17,112 | 93,484 | 819→398 (−51.4%) |
| R3 `v5c` | 25° | 18 | 0.0030 | 298 | 58,242 | ✓ | 5,773 | 93,484 | 819→398 (−51.4%) |
| **R4 `v5d`** | 25° | 14 | 0.0038 | **616** | **89,202** | **✓** | **16,476** | **66,678** | **819→366 (−55.3%)** |

逐轮反思：

1. **R1**：细节层成立但几乎看不见（0.26% 像素），且 curve→mesh 的每条 spline 两端留开口（6,656 条边界边）。
2. **R2**：加粗 + 放宽链后可见性 ×10.5，但出现成串孤立「珠链」；试 `holes_fill` 补端盖**失败**——R2 边界边反而涨到 14,560。根因：curve→mesh 的管壁与端盖顶点不共享，边界环本身不闭合，填洞补不上。
3. **R3**：改为显式共享顶点的封闭圆管，`watertight_all=True`；但把链门槛提到 18 后金线被削得几乎看不见（5,773 px）。从「杂乱」摆到了「过淡」。
4. **R4**：链门槛取 12/18 中间值 14、管径 0.0038、加自发光；柔化强度**回退半档**。结果可见性回到 16,476 px 且保持全封闭。

**柔化参数的反直觉结论**：强档（R2/R3）比弱档（R1）多改一倍像素（7.28%→14.61%），但硬跳变收益只从 −49.2% 到 −51.4%，多出来的主要是整体压暗。R4 回退半档（`DARK 0.20`、`From Max 0.62`）反而拿到 **−55.3%** 且整体压暗更小（平均亮度 −1.54 vs −2.36）。所以「看起来变化更大」不等于「边界更柔和」，必须用跳变指标判。

## 6 边界、代价、没做的事（如实）

1. **柔化只软化明暗，不改变分色线的形状**。用户最初抱怨的「颜色分割线是尖锐的曲线，而不是平滑的一条线段」，其锯齿来自分色沿离散三角边走；shader 无法把折线变成样条。要真正解决，只能回到 L9：人工定线 → `refine_seam.py` 平滑 → `split_from_drawing.py` 重切。这是**风格决定 + 人工输入**，不擅自做。
2. 少数加强筋被前方零件遮挡后只露出片段，视觉上像断续短线；已验证是贴棱（距离=管半径），不是穿模。
3. 加强筋是独立装饰对象，未参与 rest 固有 **18 对实体互穿** 的装配重设计；L11 的间隙修复与 L13 的约束都保持原状。
4. 单位仍未知：管径 `0.0038` 是文件原始坐标，若模型高 0.888≈888mm 则约 3.8mm；真要打印需先定标。
5. 本轮**没有新增倒角/凸筋/铆钉的雕刻细节**，加强筋是沿既有棱线的结构分缝表达；源 STL 几何完全未改。
6. 全部产物本地，**未做任何资产库写操作**。

## 7 在 Blender 里怎么看 / 怎么调

- 打开 **`parts_v5d.blend`**（Blender 4.4.3）。
- 大纲视图隐藏 `08_DETAIL 结构加强筋（可开关）` → 回到无筋基线；`07_CANDIDATES 候选（默认隐藏）` 仍是 L13 的 10 个候选。
- 着色器编辑器里打开任一主件材质 → 进入 `NG_L14_EdgeSoft` 组 → `SOFT_STRENGTH` 改 **0 / 1** 即可全局开关柔化。
- 视口默认 SOLID（174 万面不卡），按 `Z` → **材质预览** 才能看到 shader 柔化。
- L13 的约束仍可整体 `mute` 切自由摆姿模式；加强筋已绑骨，会跟着姿势走。
