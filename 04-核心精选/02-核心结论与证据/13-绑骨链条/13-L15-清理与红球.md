# L15 · 视口杂物清理与红球定位修正

日期：2026-11-09
基线：`parts_v5d.blend`（L14 最终版）
交付：`parts_v6.blend`

---

## 1. 用户反馈

四张 Blender 视口截图里出现两类异物：

1. 大量金色/土黄色小碎块、珠链状短线散布在腿、腰、翼附近，另有若干黑色竖线与一个蓝色箭头；
2. 髋部一个意义不明的暗红色圆球，球面上还粘着几段金色碎块。

要求：解释是什么，无实际用处的删掉；圆球解释后修改。

**本轮定性：先做全量对象清点，不凭观感动手。**

## 2. 实测诊断

### 2.1 对象清点（`l15_inventory.py` / `l15_object_inventory.json`）

| 分组 | 数量 | 可见性 |
|---|---|---|
| 主体 23 件（`CORE_` / `L_` / `R_`） | 23 | 显示 |
| `DETAIL_RIB_*` 结构加强筋 | **21** | **全部显示** |
| `MIRROR_*` 孤件镜像候选 | 4 | 全隐藏 |
| `SYMREPLACE_*` 对称替换候选 | 6 | 全隐藏 |
| 相机 / 灯光 / 骨架 | 5 | — |

`MAT_DETAIL_Rib` 的 `diffuse_color` 与节点 Base Color 都是 `(1.0, 0.86, 0.45)`，即 SOLID 视口里看到的金色。

### 2.2 三类现象各自是什么

| 现象 | 真实来源 | 是否几何 |
|---|---|---|
| 金色碎块 / 珠链 | L14 加的 21 个 `DETAIL_RIB_*`（沿锐边链生成的封闭圆管，共 89,202 面 / 616 链），在球面与光滑曲面上退化成短段 | **是，我加的** |
| 黑色竖线 / 蓝色箭头 | `PartRig` 骨架（`display_type = STICK`），未选中骨为黑线、选中骨为蓝色；视口 Overlay 显示 | **否，仅视口辅助** |
| 红色圆球 | 主体件 `L_JointPin` | **是，源 STL 自带** |

10 个候选对象全部 `hide_get / hide_render = True`，与截图里的可见杂物无关。

### 2.3 红球到底是什么（`l15_ball_diagnosis.py`）

`L_JointPin`：17,792 面 / 8,898 顶点，中心 `[-0.08185, -0.10943, 0.28987]`，半径中位 **0.01956**（三轴尺寸 `[0.03926, 0.0383, 0.03952]`，长宽比 0.993 / 0.969，接近正球）。

用 BVH 最近距离测它与其余 22 件的关系（球面 400 采样点）：

| 邻近件 | 最小距离 | 中位距离 | <0.02 的点数 |
|---|---|---|---|
| **L_Leg** | **0.000000** | **0.001492** | **400 / 400** |
| L_Hip | 0.002791 | 0.017097 | 239 / 400 |
| CORE_Spine | 0.046442 | 0.069673 | 0 |

`L_Leg` 在以球心为中心、半径 0.85R~1.35R 的壳层内有 **2,789** 个表面点。

**结论：它不是误建物，而是源 STL 拆分出的左髋关节球头/球壳，与腿件共形贴合（几乎零间隙）。** 它显得"意义不明"有三个叠加原因，全都是本流水线造成的：

1. L12/v2 把 4 个"缺对称伙伴的孤件"统一涂成醒目红色高亮，`L_JointPin` 是其中之一 → 被染红；
2. L14 在球面上生成了 `DETAIL_RIB_L_JointPin`（312 面短管）→ 球面看着脏；
3. 镜像到右侧 `x=+0.082` 处最近的 `R_Leg` 距离为 **0.0125**（中位 0.0336），右侧没有对应球 → 单侧孤立，结构不平衡。

## 3. 判定与修改

### 3.1 加强筋：无不可替代的实际用处 → 删除

- 它是**独立装饰层**，不参与 23 件主体几何、装配、骨架、约束；
- L14 已量化其可见贡献仅 2.57% 像素；
- 在曲面/球面退化成离散短段，视觉副作用明显大于收益；
- 删除后主体几何、骨架、约束、柔化 shader 全部可保持不变。

**L14 因此成为第四条被证伪的"细节"路线**（前三条：全局 Bevel、全局 Taubin、局部 ANGLE Bevel）。教训：在密三角网格上沿锐边链长出的管状细节，遇到近球面/高曲率小件必然碎成珠链；要么按零件类型白名单过滤，要么别做。

### 3.2 `build_v6.py` 实际动作

| # | 动作 | 影响 |
|---|---|---|
| A | 删除 21 个 `DETAIL_RIB_*`（89,202 面）、移除空的 `08_DETAIL` 集合、purge 无引用材质/网格 datablock | 对象数 59 → 38 |
| B | `L_JointPin` 材质复制为 `MAT_JointBall_Metal`，改中性金属色 `(0.48,0.53,0.60)`，Metallic 0.55 / Roughness 0.42；写 `L15_role` / `L15_mirror_side_missing` 自定义属性 | **仅材质，几何零改动** |
| C | 常用工作区关掉 `Overlay > Bones`（7 个 VIEW_3D），Animation 工作区保留骨骼显示 | 消除黑线/蓝箭头；摆姿势不受影响 |
| D | 保留 `NG_L14_EdgeSoft` 柔化组（23 材质共用，无几何）、保留 10 个默认隐藏候选 | 不产生可见杂物 |

**未覆盖 `parts_v5d.blend`，另存 `parts_v6.blend`（78 MB）。**

### 3.3 中途抓到的一个真 bug

第一版只改了 BSDF 的 `Base Color` 默认值，渲染出来**球仍是红色**。查节点图发现：

```
群组(NG_L14_EdgeSoft).Color = (0.97,0.26,0.30)  ──→  原理化 BSDF.Base Color
```

柔化组把自己的 `Color` 输入连线接到 Base Color，**有连线时 `default_value` 被忽略**。必须同步改组节点的 `Color` 输入。修后 V6 节点图确认该输入为 `(0.48,0.53,0.60)`，重渲染球才真正变灰。这条坑对所有接了 `NG_L14_EdgeSoft` 的 23 个材质都适用。

## 5. 边界与没做的

- **红球本体保留**：它是源 STL 的真实零件，删掉会破坏模型完整性，本轮只做视觉与语义修正。
- **结构未补齐**：右侧仍缺对称球。三个可选方向留给模型所有者定：
  1. 启用/正式化 `MIRROR_L_JointPin` 候选（17,792 面，L13 已测 0 互穿）作为 `R_JointPin`，左右对称；
  2. 把 `L_JointPin` 合并回 `L_Leg`（两者共形贴合、中位间隙 0.0015，本质像一层壳），件数 23 → 22，但会改动全链条的编号与复验口径；
  3. 直接删除该球（最干净，但丢掉源几何）。
- 其余 3 个孤件仍是红色高亮、rest 固有 18 对互穿、单位未定标、分色线几何锯齿都还在。
- 加强筋删除后 L14 的信息图/报告描述的是**历史版本**，未回改；以本文件与 `README` 的主推说明为准。
- 全部本地产物，**未做任何资产库写操作**。
