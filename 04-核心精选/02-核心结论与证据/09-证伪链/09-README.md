## 一句话结果

**`c̄ = 0.1379`，同场水平切 `0.6258`，比值 `0.2204`（目标 <0.4 达成）。** 50 万面全分辨率真实对偶图上跑的 min-cut。

## 验真（防止漂亮数字是数值游戏）

- 割线是**单一闭合环**（218 点、度数全=2），段长中位是全网格边长 1.36 倍 → 非 UV 缝/退化面抄近路。
- S 上件 143,328 面 / T 下件 356,662 面，**各为单一连通块**；y 分层 `>0.7` 时 S 占 97.7%~100%，`<0.6` 时全为 T → 干净上下分离。
- 独立几何量（与代价场无关）：割线正面(+z)端点占比 **8.3%** vs 水平环 14.0%。

## 必须知道的四个限制

1. **基线不同尺子**：文档 `0.7641` 出自 `probe_parting_B.py` 的 0.5/0.5+minmax 代价场；本实验用 `probe_visibility.py` 的 0.35/0.65+p2p98 场，合法对照是同场重算的 `0.6258`，**没有**拿 0.1379 去比 0.7641。
2. **`c̄` 低有水分**：它是 min-cut 优化目标本身，低属近乎同义反复；且割线周长 0.937 只有同高度水平截面 1.952 的一半——颈部本就细窄，不能全算作隐蔽性收益。
3. **切的是头**：割线是颈部环，沿背侧弱连接通道走，切下头部/头盔这一整块，**不是**绕躯干中部一圈。
4. **只回答"切法行不行"**：可见性是前侧暴露度代理（缺 pyembree 的真实 AO）；语义项（PartField 跨部件减价/禁切区）未启用；封盖与连接件（Step5/6）未做。

## 结论

> ⚠️ 本节结论已在下方「追加复核」中降级；保留原文以便追溯。

按文档 §5 判据，管线**成立**，可以推进到多件与 Step5 连接设计。但下一步真正该做的不是庆祝这个数字，而是补上语义禁切区与可装配约束——自由割线目前只保证代价最小，不保证能立住、能装。

## 追加复核 · 水平切基线审计（2026-11-04）

质疑：水平切「明显不行」，拿它当对照是不是虚设靶子？ → `probe_baseline_audit.py`，产物 **`baseline_audit.png`** / `baseline_audit.json`（约 44 秒可复跑）。

**结论：当「被打败的对手」无用；当「约束谱系的零自由度端点」有用，但上轮没这么用。**

做法：把 min-cut 割线强制锁在以水平切环 `y*=0.6491` 为中心、半宽 Δ 的高度带内（带外对偶边禁切），扫描 Δ。Δ→0 时 min-cut 退化为水平切 —— 两者不再是两个不可比方法，而是同一求解器在约束谱系上的两端。水平切也转成对偶图割（`inS = fc.y > y*`），与 min-cut 完全同口径。

| Δ | 自由 | 0.09 | 0.05 | 0.025 | 0.015 | **0.008** | 水平切 |
|---|---|---|---|---|---|---|---|
| c̄ | 0.1379 | 0.1379 | 0.1922 | 0.2119 | 0.3037 | **0.4309** | 0.6292 |

- 锁死高度后 c̄ 从 0.1379 升到 0.4309，**回升占「自由 vs 水平」总差距的 59.6%** → 上轮那个 4.5× 优势里约六成来自「允许自由挑切割位置」（挑细脖子），约四成才是同位置附近的局部绕行。
- Σw 分解：`0.0674 = 边数比 0.3070 × c̄比 0.2192`；对数分解下边数少贡献 **44%**、c̄低贡献 **56%**。「主要来自切得少」的直觉是错的。
- 侧面投影里橙（Δ=0.008）与青（水平切）几乎重合 → 直观证明退化关系。全部 9 档约束均可行（无被迫越界割边）。

**上轮 verdict 降级**：`成立：管线成立` → `图割链路工程跑通 + 求解器正确`，不构成方法有效性证明。原因：单一水平切对照同时改变了「位置自由度」与「局部绕行」两个变量，无法区分贡献；且 c̄ 是优化目标本身。

水平切真正的三种用途：① Δ→0 的标尺（本轮 Δ 扫描）；② 健全性自检（代价场非均匀、求解器分区正确、0.4 阈值的量级锚点）；③ **不是对手** —— 真正对照应换成人工分件接缝（现有 BOLT01 / MK02 真实分件）或下游指标（可装配 / 可平放 / 可见缝）。

> 口径提醒：本轮水平切环周长 3.153 是「锯齿状对偶割边」口径，与上轮 section 平面交线 1.952 不同，未混用。

## 再下一层 · 代价场构念效度检验（2026-11-04）

前四轮分别修了证据、类别、对照、口径，但都默认一个**从未检验的前提**：`cut_cost = 0.35×前侧暴露度 + 0.65×(1−凹度)` 能代表「好分件线」。这一层直接打这个前提。产物 **`costfield_validity.png`** / `costfield_validity.json` / `probe_costfield_validity.py`（4 秒可复跑）。

**ground truth**：`04-分件结构分析/parts_struct/_labels.npz` —— 9 万面网格 + 14 类语义部件面级标签（helmet / hair / face / torso / arm / leg / boot / weapon / backpack…）。来源 `struct_split.py` 是**用户定义的语义层级 + 高度带/前后/凸出深度规则**，与 `cut_cost` 完全独立，不是循环论证。真实接缝 = 相邻面标签不同的对偶边，**2,119 条 / 1.57%**。

**判据**：`AUC = P(接缝边代价 < 其余边代价)`，0.5 = 与随机挑边无异；另加 500 次随机抽样的 z 值与 top-k 富集度。

> ⚠️ **口径勘误（L5 发现，见文末）**：`mannwhitneyu(..., alternative="less")` 的 `U/(n1·n2)` 实为 **`P(接缝边 > 其余边)`**，上式方向写反了。本节结论**不变且更自洽**——表中「接缝均值 0.7154 > 其余 0.7061」「lift 0.767 反富集」「错方向对照 0.4778」三条独立佐证在正确口径下彼此完全一致。保留原文与数值以便追溯。

| 判据 | AUC | 接缝均值 / 其余均值 | top1.6% lift |
|---|---|---|---|
| **合成 cut_cost（主）** | **0.5185** | 0.7154 / 0.7061（**接缝更贵**） | **0.767（反富集）** |
| exposure 单项 | 0.4944 | 0.7455 / 0.7510 | 0.885 |
| 1-conc 单项（方向无关） | 0.5602 | 0.9649 / 0.9566 | 1.062 |
| cut_cost（故意错方向） | 0.4778 | 0.6658 / 0.6878 | 0.915 |

- 主判据 AUC≈0.5，且**代价场判为便宜的地方反而更不可能是真实接缝**（lift<1，最便宜 2,119 条边里接缝仅 1.23% < 全局 1.57%）。故意把相机方向设错，AUC 仍在 0.5 附近 → 不是"方向没对齐"造成的。
- `1-conc` 单项 AUC 0.5602 看着像有效度，但 z=+5.41 说明均值方向相反（接缝更平坦=更贵）、lift 仅 1.062；秩统计与均值矛盾 = 分布高度偏态、两族严重重叠，且被 exposure 项抵消后合成场归零。**不构成效度证据**。

**结论（这一层是收敛点）**：在这套 ground truth 上，几何可见性+凹度场**无构念效度**。于是前四轮所有数值（`c̄=0.1379`、Δ 扫描、Σw 分解、水平切之争）都只是在精确测量一个与分件意图无关的代理量；文档 §5 的 `c̄<0.4` 阈值也从未经任何真值标定。

- **塌掉的**：Step3 几何代价场作为「好分件线」的代理量，及以 `c̄<0.4` 为判据的最小可证伪实验设计。
- **站得住的**：对偶图图割链路工程跑通、求解器正确、非流形/绕序等入厂质检结论——这些是求解器与拓扑事实，不依赖代价场效度。
- **该去哪**：创新点必须落在**语义层**（部件标签 / 禁切区 / 装配面），几何项只能作辅助正则；且应**先建立人工分件真值集**，再谈阈值。原说明书 §5 定义的两个增量层（语义自动禁切、隐蔽∩方便的混合切）本来就在指这个方向，中间这几轮绕远了。

**必须一起看的三条限制**：① 标签是规则化语义分件、含大量硬高度带水平切面，与"藏缝"目标天然冲突——这既是标签局限，也正是目标函数选错的证据；② 它不是人工手绘真值，本实验**不能排除**"换一套人工标注真值后代价场表现变好"，结论适用范围限于"与这套规则化语义分件不一致"；③ 该模型 z-up/正面 −y，已对齐相机方向；`cut_cost` 均值在此模型 0.706、在 astronaut_kid 约 0.5，再次说明 p2/p98 拉伸后绝对值跨模型不可比。

> 要到"最终结论"，需要人工设计师标注的接缝真值（沿衣领 / 关节 / 装配面藏的缝）。在拿到它之前，不再继续在 `cut_cost` 上做任何数值打磨。

**先打开 `evidence_chain.html`**（单文件离线，点左侧任一层展开该轮原始图与数值；四张诊断图已内联，不依赖路径）或 **`evidence_chain.png`**（一页总览）。所有数字现场取自四份结果 JSON，未硬编码。

| 层 | 打的是什么前提 | 关键数字 | 判定 |
|---|---|---|---|
| L1 证据层 | UV 缝焊合 / 破洞分类 | `upload` 焊后 边界=0 / 非流形=8 / 不水密 | 构造反例撤销，真第三类=非流形 |
| L2 对照层 | Step4 min-cut 单刀两件 | `c̄=0.1379` vs 同场水平切 `0.6258`（0.2204×） | 原判成立 → 后被降级 |
| L3 口径层 | 水平切是否稻草人 | 锁高 Δ=0.008 → `c̄=0.4309`，回升占差距 **59.6%** | 对照失效，降为「图割链路跑通」 |
| L4 构念层 | 代价场认不认得接缝 | 2,119 条真值接缝上 `AUC=0.5185`、接缝更贵、lift 0.767 | **Step3 塌掉** |
| L5 能力层 | 是选错特征还是几何量没信号 | G1 上界 **0.6157**；同层语义接缝最强 disc **0.043** | **收敛**：语义层是必需项 |

### L5 本轮新证据（`feature_scan.png` / `.json` / `probe_feature_scan.py`，1.4 秒可复跑）

不打磨 `cut_cost`，改问「几何量还能不能救」。做法：14 个纯几何/位置特征逐项算判别力，再用 **Fisher LDA + 5-fold CV（零调参、闭式解）** 估几何量组合上界；标签只用于评价与分组，绝不进特征（防泄漏）。

| 判据 | 值 |
|---|---|
| 现行 `cut_cost`（L4） | **0.5185** |
| G1 纯局部几何 5-fold CV 上界 | **0.6157**（最多 +0.0972） |
| G2 局部几何＋位置 | 0.6505 |
| 最强单特征 | 边长 disc 0.1066；二面角仅 0.0544 |
| 随机噪声 / 边序号（结构对照） | 0.0005 / 0.0232 |
| 层间接缝 / 同层语义接缝 | 479 条 (22.6%) / **1,640 条 (77.4%)** |
| 层间最强 disc → 同层最强 disc | 径向 r **0.279 → 0.043**（近噪声） |

**判定**：几何量存在弱信号，但几乎全部集中在「高度层间接缝」——那只是标签由高度带规则生成的产物。占 77.4%、真正需要判断的同层语义接缝上，所有几何特征 disc ≤ 0.043。换特征最多把 AUC 从 0.5185 抬到 0.6157，**撑不起分件**；语义信息是必需项，不是可选项。L4 说的「该去语义层」从断言变成了有上界的量。

### 两处必须一起看的口径

1. **L4 的 AUC 方向勘误**（已在该节就地标注）：`U/(n1·n2)` 实为 `P(接缝 > 其余)`，L4 写成了「接缝更便宜」。其均值 / lift / 错方向对照三条佐证互相一致，**结论不变**。
2. **lift 不可跨轮比**：L5 的 lift 取「接缝更可能出现的那一端」（方向自适应），该口径下现行场 lift=1.446；L4 的 0.767 是「最便宜端」（方向固定），两者不矛盾。更要注意 **边序号这种纯结构对照 lift 也有 1.416** —— 极端尾部指标极易被网格空间连续性污染，故主判据是 disc 与 CV AUC，不是 lift。

### 最终状态

- **站得住**：对偶图图割链路跑通、求解器分区正确；非流形 / 绕序质检；Δ 约束谱系消融；接缝分组拆位置假信号；零调参 CV 上界估计。这些是求解器与拓扑事实，不依赖代价场效度。
- **塌掉 / 撤销**：Step3 几何代价场；`c̄<0.4` 判据（从未经真值标定）；水平切当对手；`1e-3·diag` 上限；v1「亚像素裂缝」构造反例。
- **仍缺（硬阻塞）**：人工设计师标注的接缝真值集；语义部件预测（PartField 类）；下游指标（可装配 / 可平放 / 可见缝）。

**下一步只有一个方向**：先建人工接缝真值集 → 用真值标定语义项与阈值 → 再谈下游可装配指标。在此之前不在 `cut_cost` 上做任何数值打磨。

> 贯穿五轮的教训：构造反例 ≠ 实测发现；没算就写断言；口径 / 尺子 / 方向每次都要先钉死。

## L6 · 「先建真值集」到底怎么做（2026-11-05）

上轮写「先建人工接缝真值集，再谈阈值」，但漏了两个会让真值集**再次失效**的前提：标注者若看过 `cut_cost` 图就会重演循环论证；没算过「标多少才够」就会变成无底洞。本轮把这两条和三项硬阻塞一起做成能打开的实物，而不是又一份方法论。

**依赖顺序（不能并行拍脑袋定）**：人工接缝真值 → 语义部件预测的训练/评测集 → 可装配约束下的阈值。

### 先打开这两个

- **`seam_annotator.html`**（3.6 MB 单文件离线，实测渲染见 `annotator_preview.png`）：9 万面模型逐面刷部件标签，左键刷标 / 右键旋转 / 滚轮缩放，支持撤销、导入续标、导出 `seam_truth/v1` JSON。已用无头浏览器自检：面拾取命中 `faceIndex=70192`、颜色缓冲写入、base64 与 9 万标签往返一致。
- **`truth_power.png`**：回答「标多少才够判定」。

### 四条硬约束（写进工具与协议）

1. **盲标**：工具内**完全不含** `cut_cost` 或任何代价场数据，标注者不可能被锚定；导出文件记 `blind_no_costfield: true`。若日后有人加回代价场显示，该份真值按 `CONTAMINATION_WARNING` 排除。
2. **真值 ≠ 导出标签全量**：默认「预填规则标签 → 人工修正」省时，但**未改动的面仍是规则生成的，不算人工判断**。评估主判据是 `edited_only`：只取人工改动面参与的对偶边（标签不同=正、相同=负，其余排除）。`full` 口径仅作与 L4 同尺子对照。
3. **纯盲标模式**可选（全 0 起点），干净但成本高；模式写入真值文件，评估端据此复算 `initial`。
4. **工具自带的佐证**：预填标签里 `eye_R` 占 26,500 面而 `eye_L` 仅 180 面——规则标签本身有明显异常，正好说明"预填不等于真值"。

### 标多少才够（`truth_power.json` / `truth_power.py`）

以 L4 同一模型**真实** cut_cost 对偶边分布为背景做 Monte Carlo（H0 AUC 0.5、H1 标定到 0.65、B=600），不是合成反例：

| n_seam | 50 | 100 | 200 | 800 | 2119(L4 现有) |
|---|---|---|---|---|---|
| AUC 95% CI 半宽 | 0.0804 | **0.0575** | 0.0370 | 0.0203 | 0.0122 |

最严口径也只需 **n_seam ≥ 100 条边 = 0.05 个模型当量**（规则标签 2,119 条接缝 / 16 个独立环链 / 平均 132.4 边）。**边数不是瓶颈**——真值集该花的力气在**代表性（≥5 个跨来源模型）、双人一致性（≥20% 重叠标 IoU/κ）、盲标纯度**，不是刷更多边。模型数/外部效度不是统计功效问题，脚本明确列为「不可算」。L4 现有 2,119 条上 `auc_cheap=0.4815`、CI `[0.4696, 0.4940]`，不覆盖 0.65；但这份稳健**只针对规则标签**，不能外推到人工真值。

> 方向口径：全文统一 `auc_cheap = P(接缝更便宜)`，L4 报的 0.5185 是反方向值 `P(接缝更贵)`。

### 另外两项的落点

- **语义部件预测**：`eval_with_truth.py --truth <导出的.json>` 一键复跑 L4/L5 指标（`full` / `edited_only` 双口径 + bootstrap CI），并附零调参多类 Fisher LDA + 5-fold CV 的最小基线；报告区分「全量 acc」（被规则标签支配）与「人工改动面 acc」。**当前 `truth_eval.json` / `.png` 是 `--selftest` 输出，仅验证代码链路，红色标注「非真值」，数字无任何有效性含义。**

## L7 · 「标面 → 推边」这个设计稳不稳（2026-11-05）

上轮把三项硬阻塞做成了工具，但 L6 标注器有个**从未检验的设计前提**：导出的是**面级部件标签**，评估端再用「相邻面标签不同」推出接缝。语义部件预测若真做出来，也必然有面级误差。本轮不碰 `cut_cost`、不需人工真值、不训练模型，只量一件可外推的事：**面标签 → 对偶边接缝这一映射的误差放大系数**。

### 先打开这两个

- **`semantic_error_viewer.html`**（3.7 MB 单文件离线；实测渲染见 `semantic_viewer_preview.png`）：7 个场景切换，模型上直接画青=真值参考 / 黄=命中 / 红=假阳性 / 蓝紫=漏检，可旋转缩放。工具内不含任何代价场。
- **`semantic_error.png`**：四面板，F1 衰减 / 假阳性膨胀 / 拓扑验真指标 / 两路线同尺子对照。
- `evidence_chain.html` / `.png` 已同步更新为 **L1~L7 七层**（数字仍全部现场取自七份 JSON）。

### 做法

三种误差形态注入同一套 9 万面 / 14 类规则化标签，横轴统一用**实测**面错标率（不用预设参数）：`iid` 逐面散点错标；`patch` BFS 成片误判（语义分割典型形态）；`boundary` 只翻转真缝两侧面（边界定位偏移一个面宽）。每档 3 个种子。对照路线 D：用 L5 同款 G1 几何特征 + Fisher LDA 5-fold CV 的 out-of-fold **真实分数**（非合成），取 oracle 等规模 top-k 直接预测边。

### 数值（`semantic_error.json` / `probe_semantic_error.py`，0.7 秒可复跑）

| 形态 | 面错标率 | 边级 F1 | 精确率 | 预测缝膨胀 | 连通分量 |
|---|---|---|---|---|---|
| iid 散点 | 1.00% | **0.616** | 0.445 | 2.24× | 782 |
| iid 散点 | 5.00% | 0.245 | 0.140 | 7.10× | 2,889 |
| 成片误判 | 4.98% | **0.820** | 0.723 | 1.31× | 20 |
| 成片误判 | 19.96% | 0.525 | 0.386 | 2.14× | 25 |
| 边界抖动 | 1.61% | **0.414** | 0.356 | 1.39× | **16** |
| 路线 D 几何直接边级 | — | **0.0384**（oracle 上界） | — | — | — |

真值基线：2,119 条接缝 / 16 个闭合环 / 度数=2 占比 0.9934；随机挑边 F1 = 0.0309。

**① 放大机制**：每个错标面污染约 **2.9 条**对偶边（≈对偶平均度 3）。iid 一阶解析式 `E[FP] ≈ (1−(1−p)²)·N_non·(1−1/K)` 与实测吻合（p=0.5%：观测 1,321 / 理论 1,231 条）→ 放大来自**邻接结构**，不是实现 bug，可用部件粒度与平均度外推到别的分件体系。接缝只占 1.57%，少量面误差即淹没稀疏正类；1.61% 的面误差产生 2,963 条错误边决策，超过真值总量 2,119。

**② 误差「形态」比「率」更关键**：成片误判 5% 面错标仍 F1=0.820，边界抖动仅 1.61% 就压到 0.414。语义预测的验收指标必须是**边界定位精度 / 边 F1**，面级 accuracy 毫无约束力（面 acc 98.4% 时边 F1 可只有 0.414）。

**③ 拓扑验真盲点（本轮最该记住的一条）**：boundary 全 5 档**连通分量恒为 16**、膨胀仅 1.01×~1.39×，与真值无从区分，但 F1 从 0.902 掉到 0.414。更硬的证据是**排序反转**：iid@0.5%（F1 0.762、分量 412）按正确性明显好于 boundary@1.61%（F1 0.414、分量 16），按分量数却完全相反。→ **L2 曾用「割线是单一闭合环 / 上下件各单一连通块」证明 min-cut 不是数值游戏，这类拓扑指标只能检出「碎裂」，查不出「整条缝被平移一格」**。度数=2 占比会降（0.992→0.825），但它度量局部粗糙度，不是位置正确性。闭合环是拓扑性质，与位置正确性无关。

**④ 两条路线同尺子**：语义面标签路径全档 F1 **0.245~0.980**（最差的边界抖动档 0.414 仍是几何上界的 **10.8×**），几何直接边级路径的乐观 oracle 上界只有 **0.0384**（随机 0.0309）。L5 报的 AUC 0.6157 听起来像「弱信号」，翻译成实际分件决策后等于不可用。**语义层是唯一值得走的方向**，但 L4/L5 的「语义是必需项」从定性断言变成了有对照的量；同时说明：光有语义还不够，边界精度才是瓶颈。

### 对 L6 标注协议的具体修订（写进规格，不是建议）

1. 真值文件增加显式 **`seam_edges` 数组（边 id）**，人工直接确认过的边才进主判据；不要只导出面标签再推导。
2. `edited_only` 口径再加一条：**边的两个面都被人工确认过**才纳入，只改一侧会系统性把接缝平移一格（正是本轮 boundary 形态）。
3. 双人一致性在**边 id** 上算 IoU/κ，不在面标签上算 acc。
4. 语义部件预测若立项，验收指标为「接缝边 F1 / 边界偏移面数」，不是面级 accuracy。

### 必须一起看的限定

- 真接缝仍是 `struct_split.py` 的**规则化语义分件，不是人工手绘真值**；本实验不主张其语义正确，只量面→边映射的放大系数。绝对 F1 依赖这套标签的部件粒度，跨体系外推请用解析式与平均度重算。
- `face_err=0 → F1=1` 是 `L̃=L` 的**恒等恢复**，图中已显式标为「非效度证据」；看的是曲线下降速度。
- 三种噪声是误差形态的可控注入，**不是真实语义分割模型的实测性能**；路线 D 的 top-k 用真值选 k，属乐观 oracle 上界。
- 本轮**没有**重跑 `cut_cost` 数值打磨，也**没有**产生人工真值。

### 一键命令

```bat
python probe_semantic_error.py        :: 重算放大曲线 + 数据 + 四面板图
python gen_semantic_viewer.py         :: 重建 3D 对比器
python gen_evidence_chain.py          :: 重建 L1~L7 证据链
```

### 状态

- **新增站得住**：面→边误差放大系数（解析式核对、可外推）；误差形态对比；拓扑验真盲点的排序反转证据；标注协议的边级规格。
- **新增撤销**：把「割线是闭合环 / 分量数」当作**有效性验真**（只能查碎裂，不能查位置）。
- **硬阻塞不变**：人工真值集仍未产生，只是现在知道该**标边**而不是标面了。

## L8 · 语义层「可学性」实测：L7 的高 F1 是上界，不是成绩（2026-11-06）

L7 的 ④ 写着「语义面标签路径全档 F1 0.245~0.980，是几何上界的 10.8×，语义层是唯一值得走的方向」，但同一节限定里也承认「三种噪声是注入，**不是真实语义分割模型的实测性能**」。也就是说那串 F1 全是**从真标签 L 出发加噪**得到的：它是「给定多准的标签 → 边 F1 会是多少」的传递函数，不是「从网格能预测出多准的标签」。把传递函数的输出当成路线的可达性能，是把上界当成绩。本轮补上缺失的那一环。

### 先打开这两个

- **`semantic_learnability_viewer.html`**（4.7 MB 单文件离线）：7 个场景，`?s=0..6` 可直达。14 色=部件标签；红=错标热力；青线=真接缝；黄线=预测接缝。**`?s=6` 的分箱组错标热力是关键一张**：面 acc 93.6%，红色错标却恰好沿青色真缝密集分布。无头浏览器实测见 `learnability_viewer_preview.png` / `learnability_error_preview.png`。
- **`semantic_learnability.png`**：四面板（分类性能 / 每类 recall / 同 acc 双柱硬对照 / 传递函数回代）。

### 做法

真的从网格零调参预测 14 类面标签：多类 Fisher LDA 闭式解 + 5-fold CV（与 L5/L7 同款，shrinkage 固定 1e-3，不做任何超参搜索）。特征严格拆三组：**G** 纯局部形状（法线/二面角/面积/凹度/暴露度/边长，**不含任何位置**）、**P** 纯位置（面质心 + 二次项）、**GP** 合并；阴性对照为随机噪声与面序号；另设**循环上界组**「位置 24×24×32 分箱多数表决」（故意允许把空间分区整个背下来）。主口径面级随机 CV（有邻接泄漏，属乐观），另跑**空间块 5-fold**（3D 网格块整块分折）作严格对照。预测标签按 L7 同口径「相邻面标签不同」推接缝。

### 数值（`semantic_learnability.json` / `probe_semantic_learnability.py`，1.1 秒可复跑）

| 特征组 | 面 acc | balanced acc | macro-F1 | 面错标率 | 边 F1 | 精确率 / 召回率 | 预测缝膨胀 |
|---|---|---|---|---|---|---|---|
| 常数全猜最大类 | 0.3167 | — | — | 0.6833 | 0.0000 | — | — |
| **G 纯局部形状** | **0.3190** | **0.0975** | 0.0838 | 0.6810 | **0.0221** | 0.0119 / 0.1605 | 13.50× |
| P 纯位置 | 0.8585 | 0.8056 | 0.7647 | 0.1415 | 0.0544 | 0.0618 / 0.0486 | 0.79× |
| GP 形状+位置 | 0.8648 | 0.8234 | 0.7723 | 0.1352 | 0.0672 | 0.0532 / 0.0911 | 1.71× |
| 阴性 随机噪声 | 0.3167 | 0.0714 | 0.0344 | 0.6833 | 0.0000 | 0 / 0 | 0.00× |
| **循环上界 位置分箱表决** | **0.9360** | 0.8695 | 0.8812 | 0.0640 | **0.1154** | 0.0760 / 0.2393 | 3.15× |

空间块 CV（消除邻接泄漏）：G **0.2795** / P **0.8316** / GP **0.8282** —— 位置组只掉 2~4 个点，说明它不是靠偷看邻面，而是在稳定地复述空间规则。均匀先验对照把 G 的 balanced acc 从 0.0975 抬到 0.2018，边 F1 仍只有 0.0296。

**① 纯局部形状认不出语义部件**：G 的 acc 0.3190 与「全猜 torso」0.3167 相差 0.0023，14 类里 **6 类零召回**。13.5× 的预测缝膨胀带来 0.1605 的召回，是「乱猜多切」偶然覆盖，不是能力；F1 0.0221 甚至低于 L7 的随机挑边基线 0.0309。

**② 位置组的高分是循环，不是语义**：`struct_split.py` 用 z 硬阈值 / y 前后 / 椭圆核 / 局部凸出深度 / 连通域过滤生成标签。允许把空间分区背下来，acc 可达 **0.9360**。这套「语义真值」93.6% 可被纯位置硬分区复现 → 它测的是空间分区，不是部件识别，**不能充当语义预测的监督集或评测集**。

**③ 面 acc 与边 F1 彻底解耦（本轮最硬的一条）**：L7 曲线横轴 `face_err = 1 − acc`，所以真实预测与 L7 在**同一横轴**上直接可比，无需任何外推。在 patch 曲线实测档位包围的 3 组上，同 acc 下实测边 F1 平均只有 L7 预期的 **11.58%**：

| 组 | 面 acc | 实测边 F1 | 同 acc 下 L7 patch 预期 | 落差 |
|---|---|---|---|---|
| P 纯位置 | 0.8585 | 0.0544 | 0.6077 | 11.2× |
| GP 合并 | 0.8648 | 0.0672 | 0.6186 | 9.2× |
| 位置分箱表决 | 0.9360 | 0.1154 | 0.7737 | **6.7×** |

G 组 `face_err=0.681` 超出 L7 全部档位（最大 0.1996），图上画成**空心点**并标「外推无效」，不计入证据。即便允许它作弊到 93.6% 面 acc，边 F1 0.1154 仍低于 L7 认为最差的 boundary 档 0.414。

**④ 真实误差是 L7 没覆盖的第四种形态**：错标面邻接自相关 P=6.46 / 分箱=8.74（iid 锚≈1）→ 成片；贴真缝比例仅 0.12~0.24（干净 boundary 形态应≈1）；`eye_L / eye_R / backpack` 三个小部件（<1000 面）的**接缝召回均值只有 0.263**。即「成片误差 + 小类整体被吞 + 边界形状改变」，L7 的 iid / patch / boundary 三种注入都不像它，故传递函数系统性高估可达性能。特别地 P 组面 acc 85.85% 却只找回 **4.86%** 的真接缝——面标签大体对了，但相邻面标签几乎处处相同，缝根本没被推出来。

### 对前几层结论的修订

1. **L7 ④ 降级**：`语义层是唯一值得走的方向`（带 F1 0.245~0.980 的性能暗示）→ 拆成两条：
   - **保留**：L5 的「语义信息是必需项」仍成立（纯几何量 CV 上界 0.6157、同层语义接缝 disc 0.043）；
   - **撤销**：把 L7 的 F1 区间当作语义路线的**可达性能**。它是给定真标签的上界；真从几何预测，现有证据下最高只到 0.1154。
2. **L6 标注器再加一条硬约束**：预填规则标签中 **93.6% 是空间分区的复述**，不是语义。`edited_only` 口径（只取两面都人工确认过的边）从「省事建议」升级为**必需**；人工真值必须来自设计师藏缝意图，不能用任何几何规则生成后当真值。
3. **语义部件预测若立项**：本轮只说明线性零调参模型学不出，**不声称深度模型也学不出**；但验收必须用边 F1 / 边界偏移，且评测集不能是这套规则标签。

### 必须一起看的限定

- 真标签仍是 `struct_split.py` 的**规则化语义分件，不是人工手绘真值**；本轮不外推到人工藏缝意图。
- LDA 是线性零调参模型；深度网络 / 大模型可能显著更高。本轮结论是「现有证据下无可学性支撑」，不是「语义不可学」的普遍命题。
- 面级随机 5-fold 有邻接泄漏（乐观）；已用空间块 CV 对照。位置分箱表决是**故意作弊的循环对照组**，绝不当部件识别能力。
- L7 回代用对数横轴线性插值，`interpolation_valid_by_shape` 标出每形态是内插还是端点外推；G 组外推不计入证据。高 `face_err` 下 boundary 锚点会饱和到真缝两侧面集合，只作定性对照。
- 本轮**未**重跑 `cut_cost`，**未**产生人工真值。

- **新增站得住**：14 类面标签的零调参可学性基线；纯局部形状 ≈ 常数基线；位置可复现度 93.6% 的循环量化；同 acc 下 11.58% 的硬落差；真实误差形态不属于 L7 三种注入。
