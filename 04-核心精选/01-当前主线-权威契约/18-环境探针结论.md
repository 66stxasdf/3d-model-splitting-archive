# 环境可行性探针结论（A-5，2026-11-11）

> ROADMAP §三 阶段 1 第 5 项。**只探不装**——安装是阶段 2 的事。
> 目的：防止阶段 2 装到一半才发现墙。事实来源见 `文献可用性对照表.md`。

## 一、权重可获取性（已核实）

| 方案 | 结论 | 来源 |
|---|---|---|
| **PartField**（阶段 2 首选） | ✅ **可获取**：代码 `github.com/NVlabs/PartField`；权重 HuggingFace `mikaelaangel/partfield-ckpt`（`model_objaverse.ckpt`）。**注意：仅 Objaverse 训练版；PartNet 版因授权不发布**——将来要在 PartNet 分布上对比只能自训，先记账 | HF 卡 + NVlabs README（2026-11-11 核实） |
| **SAMesh / Segment Any Mesh**（对比线） | ✅ **可获取**：代码+数据集 `github.com/gtangg12/samesh`；另需 SAM2 权重（随用随下） | 官方仓库（2026-11-11 核实） |

**没有一条卡在版权/付费墙上**——这与 Tripo/3d66 的实测结论（付费墙/登录墙）形成对照：
开源学术线的获取成本远低于商业 AIGC 平台。

## 二、GPU 硬需求（已核实）

- PartField README 明确：**Python 3.10 + PyTorch 2.4 + CUDA 12.4**（RTX 5090 需 CUDA 12.8 分支）。跑它必须有 CUDA GPU，没有 CPU 退路。
- SAMesh 基于 SAM2，同样要 GPU；且两阶段（多视角渲染 + 抬升）比 PartField 重。

## 三、8GB 显存够不够：架构层面乐观，官方无数字，阶段 2 实测

**能说的**（Paper-Notes 整理的架构细节 + PVCNN 原论文）：
- 输入仅 **10 万点/形状**（可调）；triplane **512²×128 通道**，特征 448 维，6 层 Transformer
- PVCNN 的设计目标就是省显存（原论文：比体素路线省 10× 显存）
- 推理 <10s/件（论文口径）

**不能说的**：官方未给推理显存峰值。8GB 是乐观推断，**不是事实**。

**阶段 2 装机第一步就是实测**：`nvidia-smi` 盯峰值。备好的退路（按代价排序）：
1. 降输入点数（100K → 50K/25K，README 级参数）；
2. 聚类放 CPU（agglomerative 在 trimesh/scipy 上跑，不占显存）；
3. 分块推理（lod 版先跑、原版交付，与 `prep_lod` 的分层设计天然对齐）。

## 四、无 GPU 备选路线（若阶段 2 撞墙，已定）

ROADMAP 预案「人工关键点 + 测地距离 + 标定库」展开为可执行形态：
1. **人工关键点**：标注工具（阶段 1 A-6）在目标域样本上点种子（头/手/四肢…）；
2. **测地距离**：trimesh 的 `nearest.on_path` / graph 最短路径做区域内生长，
   边界 = 测地距离等值线（几何量，不依赖学习）；
3. **标定库**：种子+生长参数按「模型类型 × 姿态」归档成 JSON，
   新模型先查库（同类型直接套参数），库里没有的才人工补——
   这就是「标定库」越用越全的机制，与 B 线错误记忆同构（都是查表先验，不是权重更新）。
此路线不装任何深度学习环境，阶段 1 的全部资产（trimesh/numpy/scipy）就够。

## 五、阶段 2 装机顺序建议

1. **只装 PartField 一线**（conda env：python 3.10 + torch 2.4 + cu124 + 其依赖表），
   在 48 件真值 + cand-02/03 上跑通，`parts_available` 校验器出第一张成绩单；
2. 跑通后再装 SAMesh 作对比线——不要一开始就铺两条环境，
   环境问题是阶段 2 最常见的沉没成本来源；
3. 装机前先 `nvidia-smi` 确认本机显卡与可用显存，把数字记进 run 环境段。

## 六、停手条件（对应该探针）

- 拿不到权重 → 已核实可拿，此条不触发；若 HF 链接失效，回退 NVlabs 项目页重新定位；
- 8GB 实测跑不动 → 按第三节退路 1-3 降级，仍不行 → 转第四节无 GPU 路线，
  **不硬扛、不买机器**（`DGXSpark训练选型论证.md` 是远期论证，不是本阶段依据）。
