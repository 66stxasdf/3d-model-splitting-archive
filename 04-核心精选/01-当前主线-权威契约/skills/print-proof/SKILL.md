# 可打印性与装配证明

## 零、先看清交付有三档，别把最低档说成最高档

契约里三个目标组的终点不同：

| 目标 | 达成的事实 | 意味着什么 |
|---|---|---|
| `deliver` | `part_exported` | **件出来了**，但连接可能还没做 |
| `joints` | `joints_verified` | 每对连接都验过了 |
| `full` | `part_exported` + `joints_verified` + `assembled_ok` | **真的能拼** |

`export_part` 只需要 `part_verified`，不要求任何连接事实。
所以「件全部导出成功」完全可能与「一碰就散」同时成立。

报告里说「已交付」时必须指明是哪一档。

---

## 一、立即停手的情形

### 1. 拿躺倒的件和站立的原件比体积 → 停

为打印做了姿态变换（旋转 / 平移 / 可能缩放）之后，**坐标已经不在模型系里**。
此时与原模型直接比体积或比 bbox，比的是两个不同姿态的东西。

必须先逆变换回模型坐标系（或对原件施加同一变换），再比。
症状：体积差 30% 以上且与切缝位置无关，或 bbox 并集还原偏差几十毫米。

### 2. 只量最近邻间隙就说「能装」→ 停

最近邻距离小只说明两个面靠得近。它可能是：
- 两个凸起在最近点擦过（实际并不接触）
- 实际穿插（负距离被绝对值抹掉）
- 接触点在切缝外

「装得上」必须有**约束层面**的证据：≥2 根销、实测径向间隙、干涉体积为零、
装配体体积回原体积。缺任一，不许写「可装配」。

### 3. 悬垂 / 支撑靠截图判断 → 停

**本链零代码**。没有面法向与打印方向的统计工具。
任何「我看了一下，应该不需要支撑」都是无证据判断，必须记 `UNKNOWN`。

正确动作：写人工动作项（「在切片软件里加载，检查悬垂高亮」），结论上限 `PASS_WITH_MANUAL`。

### 4. 把 `min_wall_mm = 0.8` 当作设计下限 → 停

0.8 是 `clean_part` 的**剔除阈值**——低于它算碎片，自动剔掉。
**设计下限是 1.2mm**（3 圈 @0.4 喷嘴）。

按 0.8 设计会得到「2 圈壁厚」的件：层间结合不足、轻微挤出过量就鼓包、受力即裂。
两者差 50%，在报告里表现为「壁厚检查通过」而实物是废件。

### 5. `unit_confirmed == false` 却写「可直接打印」→ 停

单位从未实测标定。任何绝对尺寸结论（壁厚 1.2、间隙 0.2、留厚 1.5）
都建立在「文件声明的单位是真的」这个假设上。

报告必须带这句：「尺寸按 mm 口径判定，单位未实测标定。」
上限 `PASS_WITH_MANUAL`（人工拿卡尺核一个已知特征）。

### 6. 单件复验失败就把整批判死 → 停（`skip_instance`）

`verify_part` / `export_part` 的失败策略是 **`skip_instance`**：
一件失败只放弃这一件。

正确做法：失败件剔除出清单并**逐件**记账，其余继续。
不许把失败件算进「全部通过」，也不许因为一件失败就判整批失败。

## 二、判据

### 2.1 单件复验（`verify_part` → `part_verified`，对应 G7）

每件各自核对四项：**水密、自交、体积、壁厚**。
结果由校验器**从磁盘重算**，工具说的不算。

阈值默认值：

| 项 | 阈值 |
|---|---|
| 体积相对误差 | **< 0.1%**（0.001）|
| bbox 并集还原偏差 | **< 0.01 mm** |
| 两件互不嵌入 | **< 1%**（0.01）；> 0.3% 出 WARN |
| 切面共面 | 按报告 |

**空 checks → `UNKNOWN`，不是 PASS。** 这是防「校验器什么都没查就说通过」。

### 2.2 导出（`export_part` → `part_exported`）

每件各自导出 **STL + 3MF**。分开导出才能真正分开打印。

判据：文件数 = 件数 / 逐件回读一致 / 记录 `unit` 与 `unit_confirmed`。

回读一致是防「导出时丢了面或改了精度」。文件在、能打开，不等于内容对。

### 2.3 装配（`assemble_check` → `assembled_ok`）

前置是 `joints_verified` **和** `part_exported`，即：件出完了、每对连接都验过了，才做整体装配。

核对：全部连接按最终姿态对齐后，整体能拼成一个、不穿模、站得住。

注意它**不是 advisory**（0.2.0 里它是 `abort` 策略），失败会中断。
这和 0.1.0 那版不同，别按旧印象把它当软闸门。

### 2.4 打印可行性（技能层判据）

| 项 | 值 | 性质 |
|---|---|---|
| 设计壁厚 | ≥ **1.2 mm** | design |
| 薄片剔除线 | **0.8 mm** | reject（不是设计线）|
| 悬垂 | > 45° 需支撑 | hard（**检测 absent**）|
| 桥接跨度 | ≤ 10–15 mm | hard（**检测 absent**）|
| Z 向强度 | XY 的 60–80% | design |
| 可平放 | 朝下面积占比 ≥ 10% | design |

前两条能算，后四条本链算不了。**不要用「包围盒朝下面积」冒充悬垂分析。**

## 三、需要的证据

- 每件的复验报告（含逐项实测值，不是布尔汇总）
- 每件的姿态变换记录（逆变换要用）
- 导出回读报告
- 装配报告（间隙实测、干涉体积、整体对齐偏差）
- `unit` / `unit_confirmed`
- 失败件清单及原因（`skip_instance` 逐件记账）

---

## 四、放行条件与结论分级

按**证据强度**给结论，不许一律写 PASS：

| 结论 | 条件 |
|---|---|
| `PASS` | 全部 `implemented` 项通过，且 `unit_confirmed == true` |
| `PASS_WITH_WARN` | 有 `advisory` 项未过（如互穿 0.3–1% 的告警）|
| `PASS_WITH_MANUAL` | **有 `absent` 项**（悬垂 / 装配稳定性）或 `unit_confirmed == false` |

当前默认落在第三档：悬垂检测与单位标定都是 `absent`。
**写成 `PASS` 就是撒谎**，而且是最容易发生的那种——因为工具指标确实全过。

同时必须标明交付档位：`deliver`（件出了）/ `joints`（连接验了）/ `full`（能拼）。
三档混说的典型症状是：报告写「全部完成」，用户拿到一堆件，发现拼不起来。

## 五、能力状态

| 能力 | 状态 | 说明 |
|---|---|---|
| 单件水密 / 自交 / 体积 / 壁厚 | `implemented` | `verify_part` |
| 导出与回读 | `implemented` | `export_part` |
| 整体装配核对 | `implemented` | `assemble_check` |
| 打印朝向 | `advisory` | 只出 WARN，**永不 PASS** |
| **悬垂 / 支撑判定** | `absent` | 零代码 → 强制 `UNKNOWN` + 人工动作项 |
| **桥接跨度** | `absent` | 同上 |
| **装配稳定性（落下仿真）** | `absent` | 无仿真，不得声称「摔不散」 |
| 单位实测标定 | `absent` | `unit_confirmed: false` 至今 |

注意 `assemble_check` 证明的是「**几何上对得齐**」，
不是「**摔一下不散**」。后者需要物理仿真，本链没有。
