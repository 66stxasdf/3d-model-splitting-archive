# 连接结构

**这个技能是整条链的价值分水岭。**
SNAP3D 实测：只做语义分件、不加连接，重力落下稳定性 ≈ **0%**；加连接 + 物理仿真才到 **95%**。
分得再准，拼不回去就是零。所以本技能的门槛应当比切割更严，不是更松。

## 一、立即停手的情形

### 1. 只找到 1 个可用销位 → 直接拒

报 `ONLY_ONE_SLOT`，不要「先做一个试试」。

单销只约束 2 个平移自由度，绕销轴的旋转**完全自由**。结果是零件能转，
表现成「装上去了但是歪的」——而这个症状极易被误判成「孔开歪了」，
于是下一轮去修孔，越修越错。

### 2. 销长在厚件、孔开在薄件 → 停

项目实测：A 侧 **27.6mm**、B 侧 **4.2mm**。做反就是「3mm 的销插 2mm 的板」——
筷子插豆腐。装配时销会把薄件顶穿，或者薄件直接裂开。

**判据不是包围盒，是局部厚度。** 必须用 `split-intake` 产出的厚度图，
在**接触面上逐点**比较两侧厚度。包围盒厚的那侧，接触面处可能恰恰是薄的
（典型：手臂根部厚、手腕细）。

### 3. 小件接触面 < 28.3mm² → 不用销

两个数字，别混：

| 阈值 | 来源 | 含义 |
|---|---|---|
| **20.0 mm²** | 内核 `min_contact_area_mm2` | **硬下限**，低于它完全不做连接 |
| **28.3 mm²** | π×3²，一根 3mm 销的截面积 | **有效下限**，低于它连一根销都放不满 |

两者不矛盾：20–28.3 之间只放得下一根销，而单销被禁止（见第 1 条），
所以操作阈值取 28.3。硬做会得到一个「有两根销但孔间壁厚不足 1.2mm」的件，打出来就碎。

改：磁吸（需预留 0.2mm 沉孔）/ 嵌槽（靠外形定位）/ 粘接（最简，但不可拆）。
**眼睛、头发、配饰、飘带几乎全部落在这类。**

### 4. ≥3 件时未验证插入序 → 停

三件以上，每件相对**每个**邻件 ≥2 约束之外，还必须存在一条可行插入顺序：
第 3 件能装进去，不被已装好的 1+2 挡住。

这是**组合优化**，内核的反向展开推不动（`refs/pack-contract.md` 第五节已注明）。
技能侧的正确动作：**列出候选插入序，请人确认**，不要自己声称「顺序没问题」。

### 5. 想用键槽防转 → 不做

两根平行销已完全约束绕法向旋转。键槽的代价是：需对位、易卡、FDM 上槽口容易塌。
除非用户明确要求传递扭矩，否则不加。

### 6. 把「最近邻距离 < 间隙」当接触面 → 无效

两个面靠得近不等于它们是配合面：可能是两个凸起在最近点擦过，
也可能实际是穿插（负距离被 abs 掉）。
必须**双向交叉验证**：A 侧测出的面积与 B 侧测出的面积一致，法向相反。

## 二、判据（FDM / 0.4 喷嘴，详见 `refs/process-profiles.md`）

| 项 | 值 | 性质 |
|---|---|---|
| 销径 | **3.0 mm** 起（`pin_diameter_mm`）| 硬约束 |
| 单边径向间隙 | **0.2 mm**（`radial_clearance_mm`）| 硬约束 |
| 孔深余量 | 销长 **+0.4 mm** | 硬约束 |
| 孔径补偿 | 建模直径 +**0.2 mm** | 硬约束（FDM 孔印小 0.1–0.3）|
| 销间距 | ≥ **3× 销径** | 硬约束（否则孔间壁厚不足 1.2）|
| 孔底留厚 | ≥ **1.5 mm** | 硬约束（防开穿）|
| 销根留厚 | ≥ **1.5 mm** | 硬约束 |
| 约束数 | ≥ **2 根平行销** | 硬约束 |
| 装配体体积 | 回原体积误差 **< 0.5%** | 硬约束（这是唯一能证明销没歪孔没穿的量）|

**间隙一律是「单边」。** 双边说法会把 0.2 说成 0.4，直接导致松动。

**体积守恒是这里最有力的单项检查**：销的体积是增加，孔的体积是减少，
两者若严格相等则总体积不变。体积回不去，说明销做歪了、孔开穿了、或有一次布尔被静默丢弃。
这一条比目视检查可靠得多，且不需要人参与。

## 三、需要的证据

- `contacts.json`：**双侧**面积与法向（A 侧、B 侧各一份，便于交叉验证）
- 厚度图（来自 `split-intake`）：接触面处逐点厚度，不是包围盒
- `joints.json`：每个销的轴线、起点、长度、对应孔径与孔深
- 装配体体积 + 原模型体积
- 干涉体积（实测，不是标称间隙）

`verify_joint` 必须**从磁盘重读**装配后的几何算间隙，不能复用 `build_joint` 的返回值。
标称 0.2 和实测 0.2 是两回事：布尔误差、浮点、缩放都能吃掉这 0.2。

## 四、放行条件

`joints_verified` 成立，且同时满足：

1. 每个配合面 ≥2 根销
2. 实测径向间隙在 **0.2 ± 0.05 mm**
3. 干涉体积 = 0（不是 <1%，装配件必须严格不互相嵌入）
4. 装配体体积回原体积 **< 0.5%**
5. 孔底 / 销根留厚 ≥ 1.5mm

缺任一条 → 不放行。**不许「先导出，装不上再修」**——修一个已导出的件要重走整条链。

### 部分失败：`skip_instance` 的含义

`build_joint` / `verify_joint` 的失败策略是 **`skip_instance`**——一对失败只放弃这一对，其余继续。
所以内核交回的常是「部分对通过」，不是「全过 / 全不过」。

处理规则：

- 失败的对 → 降级为磁吸 / 嵌槽 / 粘接，**逐对**写进报告
- 不许因为「大部分过了」就把挂掉的对也算通过
- 不许因为「有一对没过」就把整个装配判死——除非它是主承力对

逐对记账是硬要求。不记的话，装配阶段会发现「少了一对连接」，却查不出是哪一对，
最后只能全拆重来。

## 五、能力状态

| 能力 | 状态 | 说明 |
|---|---|---|
| 接触面识别（双向）| `implemented` | `find_contacts` |
| 销孔生成 | `implemented` | `build_joint` |
| 间隙 / 干涉 / 留厚复验 | `implemented` | `verify_joint` |
| 插入序规划（≥3 件）| `absent` | 组合优化，内核推不动 → 列候选请人确认 |
| **装配稳定性（物理仿真）** | `absent` | **关键缺口** |
| 磁吸 / 嵌槽 / 粘接方案 | `absent` | 只有设计准则，无几何生成 |

**关于「装配稳定」必须诚实**：SNAP3D 的 95% 是「连接结构 **+ 物理仿真**」共同的结果。
本链只有前一半。所以我们能证的是「**几何上装得进去、不互相嵌入、体积对得上**」，
**不能证「摔一下不散」**。

因此：本技能全部通过，结论上限也是 `PASS_WITH_MANUAL`，
并必须附一条人工动作项：「实物装配后做一次 1m 自由落体，检查是否脱开」。
不得因为三个校验器都过了就写「装配可靠」。
