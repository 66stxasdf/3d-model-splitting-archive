## 四、打开 HTML 的注意事项

- `evidence_chain.html`、`seam_draw.html`、`seam_draw_new.html`、`print_manual.html`、`L19-总览.html`
  都是单文件离线页，可直接用浏览器打开；部分页面需要 WebGL，建议用 Edge/Chrome。
- `预览查看器/` 里的 `viewer.html` 需要走 HTTP（file:// 会被 CORS 拦）。在该目录下起本地服务：
  ```bash
  D:/Mangshe/python.exe -m http.server 8791
  # 浏览器打开 http://127.0.0.1:8791/viewer.html
  ```
- `20-Agent工作台.html` 是可视化面板；真正跑内核还要配合 `18-分件Agent内核/` 的 Python 环境与
  `20-build.py` / `20-bridge.py`。本精选包只带最小集，不带 runs 证据流。
